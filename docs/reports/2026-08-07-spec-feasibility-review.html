원인은 설계 실수다 — 워커를 메인 리포에서 띄우고 cd로 다른 워크트리를 쓰게 했는데, 그 워크트리를 git worktree로만 만들어 Orca가 모르는 상태였다. 다음엔 orca worktree create로 만들어 워커의 프로젝트 루트 자체를 대상 워크트리로 잡아야 한다.

손실은 시간뿐이다 — 양쪽 워크트리 git status로 파일 오염 0건을 확인했고, 읽기 전용 정찰 4개의 결과는 그대로 활용해 편집을 완주했다. 워커는 세우고 코디네이터가 직접 편집했다.
