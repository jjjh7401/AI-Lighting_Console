## 3. 리그 기하 기억 (SPATIALMEM-001, completed)

좌표는 시간이 지나 낡지 않고 **누군가 바꿔야** 낡는다. 그래서 만료 기준을
시간이 아니라 변경 사건에 뒀다.

- 완전 판독만 기억한다. `partial_fixtures` 형태는 저장하지 않는다.
- 쓰기 전 값싼 프로브: 컨테이너 1회(개수) + 표본 3대 좌표 = **왕복 4회**.
  어긋나면 전량 재판독하므로 최악이 종전과 같다.
- 모든 응답이 `freshness`를 단다. `console` / `remembered`를 구분하고,
  전수 재확인이 아니라는 한계를 한국어로 고지한다.
- `arrange_fixtures` 검증 성공 시 그 값으로 갱신, 실패 시 전체 폐기.
  `force_refresh`로 강제 갱신.

**실기 결과**: 도구 구간 9.58초 → **0.25초**, 턴 22.66초 → 10.83초.
검증 이동(z=5.0) 후 기억이 새 값을 반영한 채 적중, 원값 복원 확인.

## 4. 답변 스트리밍 (STREAM-001)

- `AnswerSink` + `answer_delta` 이벤트(additive, v=1 유지, 양쪽 allowlist 등록).

  종전 경로 그대로.
- Gemini: `provider_payload`를 **모든 청크의 파트를 합쳐** 재구성한다.
  마지막 청크만 쓰면 청크에 걸친 파트를 잃는다. 실 API로 검증했다 —
  재구성한 다중 파트 턴은 도구 루프에 재진입되고, 손으로 만든 턴은
  thought_signature 부재로 거부된다.
- 실기: 여섯 문장 답변 기준 첫 글자 **9.91초**, 완료 11.28초, 조각 16개.

**실기에서만 드러난 결함 2건**을 잡았다. `ProviderSlot`이 스트리밍을 전달하지
않아 앱이 조각을 0개 냈고, 조각 이어붙임이 확정본과 개행 하나만큼 달라 턴

이 앱은 세션 대화를 이어 붙이므로 **세 번째 지시부터** 사실상 도구를 놓는다.

**악화 요인**: 룰북 40,487자에 `Pan`/`Tilt` 34회, `Posx/y/z` **0회**,
