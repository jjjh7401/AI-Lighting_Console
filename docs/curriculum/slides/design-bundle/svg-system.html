아이콘 폰트도, 이미지 파일도 쓰지 않습니다. 색을 CSS 변수로 참조해야 테마 토큰과 절대 어긋나지 않고, 프로젝터에서 확대해도 안 깨집니다.

아이콘 규격 — SF Symbols 마감을 맞춘다

<svg viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="1.65" stroke-linecap="round" stroke-linejoin="round"
     aria-hidden="true"> … </svg>
속성값이유
viewBox0 0 24 24SF Symbols와 같은 격자
stroke-width1.6 ~ 1.7본문 아이콘. 이보다 굵으면 Apple 톤을 벗어난다
stroke-width2.2 ~ 2.6리스트 불릿(체크·엑스). 작게 쓰므로 굵게
linecap / linejoinroundSF Symbols의 둥근 마감. 이게 빠지면 즉시 티가 난다
strokecurrentColor부모의 color를 따라가 모듈색이 자동 적용된다
크기1.9em / 1.5em / 1.05em카드 / 콜아웃 / 불릿
aria-hiddentrue장식 아이콘. 의미는 옆 텍스트가 전달한다

다이어그램 클래스 — 색을 하드코딩하지 않는다

.d-box      { fill:#1C1C1E; stroke:var(--sep); stroke-width:1 }
.d-box.acc  { fill:#0F1A22; stroke:var(--blue)  }   /* 강조 노드 */
.d-box.warn { fill:#1A1416; stroke:var(--red)   }   /* 위험 노드 */
.d-box.good { fill:#0F1B14; stroke:var(--green) }   /* 안전 노드 */

.d-t  { fill:var(--lb);   font:600 13px var(--sf) }   /* 노드 제목 */
.d-s  { fill:var(--lb-2); font:11px var(--sf)     }   /* 노드 부연 */
.d-k  { fill:var(--lb-3); font:9.5px var(--sfm); letter-spacing:.1em }  /* 캡션 */

.d-ln      { stroke:var(--lb-3); stroke-width:1.4; fill:none; stroke-linecap:round }
.d-ln.warn { stroke:var(--red); stroke-dasharray:4 3 }   /* 되돌림 · 금지 경로 */
.d-ah      { fill:var(--lb-3) }                          /* 화살촉 (삼각형 path) */

화살촉은 마커가 아니라 삼각형 path로 직접 그립니다 — marker는 currentColor 상속이 브라우저마다 달라 색이 어긋납니다.
노드 모서리 rx 14~18 · 노드 간 간격 60~80 · 화살표 길이 26~64.

실물 — 26번 (통행권)

모든 다이어그램 SVG에 role="img"과 서술형 aria-label이 필수입니다.
이 덱에서 다이어그램은 장식이 아니라 정보의 본체입니다. 대체 텍스트가 없으면 접근성이 나빠지는 게 아니라 내용 자체가 사라집니다. aria-label은 "무엇이 그려져 있다"가 아니라 "이 그림이 말하는 것"을 문장으로 씁니다 — 위 두 예시의 라벨을 참고하세요.
