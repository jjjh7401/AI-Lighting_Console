16:9 프레임과 그 안의 규칙

모든 슬라이드는 1280 × 720 비율 고정입니다. 실제 픽셀은 화면에 따라 달라지지만 비율과 내부 간격 비는 절대 안 변합니다 — 컨테이너 쿼리 기반이기 때문입니다.

프레임 코드

.slide {
  container-type: inline-size;      /* 이 한 줄이 전체 스케일의 기준 */
  aspect-ratio: 16 / 9;
  width: 100%;
  font-size: 1.5625cqw;             /* 1280px → base 20px */
  background: #000;
  padding: 3.2em 3.6em 2.8em;
  display: flex; flex-direction: column; gap: 1.1em;
  border-radius: .75rem; overflow: hidden; position: relative;
}
.slide::before {                    /* 모듈 레일 */
  content: ""; position: absolute; left: 0; top: 0; bottom: 0;
  width: .3em; background: var(--hue);
}

인쇄 · 배포

@media print {
  .slide { border-radius: 0; box-shadow: none; break-after: page }
  @page  { size: landscape; margin: 0 }
  .note, .deckbar, .framehead { display: none !important }   /* 발표자 노트는 인쇄 제외 */

넘침 금지가 이 덱의 1차 품질 기준입니다. 슬라이드는 스크롤되지 않는 고정 프레임이라 내용이 넘치면 잘려서 사라집니다.
검수할 때 모든 슬라이드에 대해 scrollHeight > clientHeight가 0건인지 확인합니다. 넘치면 카드 개수를 줄이거나 .head를 .head.sm으로 내립니다.
