SF Pro + Apple SD Gothic Neo

웹폰트를 링크하지 않습니다 — macOS·iOS에서 -apple-system이 SF Pro와 Apple SD Gothic Neo를 실제로 잡습니다. 그 외 환경은 Pretendard로 폴백합니다.

/* 본문 · 제목 */
--sf : -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text",
       "Apple SD Gothic Neo", "Pretendard", "Noto Sans KR", system-ui, sans-serif;

/* 데이터 · 라벨 · 코드 */
--sfm: ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace;

슬라이드 전체가 통째로 스케일된다

슬라이드마다 폰트 크기를 다시 잡지 않습니다. 컨테이너 쿼리 단위로 base를 정하고 내부는 전부 em — 창을 줄이든 프로젝터에 띄우든 비율이 그대로 유지됩니다.

.slide {
  container-type: inline-size;
  font-size: 1.5625cqw;   /* 1280px 폭 → base 20px */
}
/* 이하 슬라이드 내부는 전부 em. px를 쓰지 않는다 */
.head { font-size: 2.15em }   /* = 43px @1280 */

한글 조판 — 이게 빠지면 발표 화면에서 급격히 안 읽힌다

❌ 기본값
조명감독을 위한 AI 도구 제작 과정
word-break 기본값이면 한글이 음절 단위로 잘립니다. 좁은 칸에서 특히 심하고, 읽는 속도가 눈에 띄게 떨어집니다.
✅ keep-all
조명감독을 위한 AI 도구 제작 과정
word-break: keep-all + line-break: strict — 어절 단위로 끊깁니다. 슬라이드 전역에 적용합니다.

굵기 주의 — Apple SD Gothic Neo는 700 이상에서 급격히 굵어집니다. 한글 제목에 800~900을 쓰면 프로젝터에서 획이 메꿔집니다. 제목 700, 부제 650, 본문 400을 넘기지 않습니다.
