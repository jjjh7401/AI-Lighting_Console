## 0. 한 장 요약

| 항목 | 값 |
|---|---|
| **무엇** | 조명감독·조명 전공학생 대상 「AI로 내 도구 만들기」 인식 강연 슬라이드 |
| **분량** | 34장 · 16:9 (1280 × 720 기준) |
| **편성** | 3시간 1회 특강 — 정규 30시간 과정의 축약본 |
| **청중** | AI·프로그래밍 **사전 지식 0** 전제. 현업 조명인 + 전공 학생 혼합 |
| **디자인 시스템** | **Apple HIG · Dark Appearance** (시스템 색 + SF 타입 스케일) |
| **테마 정책** | **슬라이드 면은 항상 다크 고정**(투사면). 뷰어 테마는 슬라이드 바깥 여백에만 반영 |
| **언어** | 전량 한국어. 영문은 라벨(eyebrow·태그)에만 |
| **금지** | 시간 예측 표현("2일이면") · 근거 없는 숫자 · 성공담 톤 |

### 톤 앤 매너 (이게 어긋나면 다른 건 다 맞아도 실패다)

1. **일상어 먼저, 용어는 뒤에.** ✅ "AI가 지금 기억하는 내용 — 이걸 컨텍스트라고 합니다" / ❌ "컨텍스트가 부족하면…"
2. **성공담으로 만들지 않는다.** 실패 사례 슬라이드(28·29번)가 이 덱의 클라이맥스다. 시각적으로도 가장 강해야 한다.
3. **모든 숫자는 실측값이다.** 443 · 131 · 63 · 28 · 25 · 10 — 장식이 아니라 근거다. 임의로 바꾸지 않는다.
4. **조명 비유가 뼈대다.** 리밋 스위치 · 백스테이지 패스 · 무한 체이스 · 채널→밝기→패치. 비유를 빼면 전달이 안 된다.

### 1-3. 타이포그래피

```
--sf  : -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text",
        "Apple SD Gothic Neo", "Pretendard", "Noto Sans KR", system-ui, sans-serif
--sfm : ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace
```

슬라이드 전체가 **컨테이너 쿼리로 통째 스케일**된다 — `.slide { container-type: inline-size; font-size: 1.5625cqw }` → 1280px 폭에서 base 20px. 내부는 전부 `em`.

| 역할 | 크기 | 굵기 | 자간 | 비고 |
|---|---|---|---|---|
| 표지 제목 | `2.9em` (58px) | 700 | `-.022em` | `text-wrap: balance` |
| 섹션 표지 모듈번호 | `4.6em` (92px) | 600 | `-.04em` | 모노, 모듈색 |
| 슬라이드 제목 `.head` | `2.15em` (43px) | 700 | `-.022em` | |
| 슬라이드 제목 `.head.sm` | `1.75em` (35px) | 700 | `-.022em` | 본문 많은 장 |
| 인용 `.q` | `2.05em` (41px) | 600 | `-.022em` | |
| 리드 `.lede` | `1.05em` (21px) | 400 | — | `--lb-2` |
| 카드 제목 | `1em` (20px) | 600 | `-.008em` | |

**한글 조판 필수 설정** — `word-break: keep-all` · `line-break: strict` (어절 단위 줄바꿈). 이게 빠지면 한글이 음절 단위로 잘려 읽기가 급격히 나빠진다.

**숫자** — 수치가 세로로 정렬되는 곳은 전부 `font-variant-numeric: tabular-nums`.

| 항목 | 값 |
|---|---|
| 슬라이드 패딩 | `3.2em 3.6em 2.8em` (상 64 / 좌우 72 / 하 56 px) |

### 아이콘 규격

- **인라인 SVG만** (아이콘 폰트·이미지 금지)
- `viewBox="0 0 24 24"` · `fill="none"` · `stroke="currentColor"`
- `stroke-width` **1.6~1.7** (본문 아이콘) / **2.2~2.6** (체크·엑스 불릿)
- `stroke-linecap="round"` `stroke-linejoin="round"` — **SF Symbols의 둥근 마감을 맞춘다**
- 크기: 본문 아이콘 `1.9em`, 콜아웃 `1.5em`, 리스트 불릿 `1.05em`
- 전부 `aria-hidden="true"`

## 3. 다이어그램 명세 (8종)

전부 인라인 SVG. **색은 CSS 변수로 참조**해 테마 토큰과 어긋나지 않게 한다.

```
.d-box  { fill:var(--sf-1); stroke:var(--sep); stroke-width:1 }
.d-box.acc  { fill:#0F1A22; stroke:var(--blue) }    /* 강조 */
.d-box.warn { fill:#1A1416; stroke:var(--red) }     /* 위험 */
.d-box.good { fill:#0F1B14; stroke:var(--green) }   /* 안전 */
.d-t  { fill:var(--lb);   font:600 13px var(--sf) }   /* 노드 제목 */
.d-s  { fill:var(--lb-2); font:11px var(--sf) }       /* 노드 부연 */
.d-k  { fill:var(--lb-3); font:9.5px var(--sfm); letter-spacing:.1em }  /* 캡션 */
.d-ln { stroke:var(--lb-3); stroke-width:1.4; fill:none; stroke-linecap:round }
.d-ln.warn { stroke:var(--red); stroke-dasharray:4 3 }   /* 되돌림·경고 경로 */
```

| 슬 | 이름 | viewBox | 무엇을 그리나 |
|---|---|---|---|
| 02 | 3시간 구성 | `0 0 1000 250` | PART 1 → 2 → 3 가로 3블록. 가운데(PART 2)만 강조 |
| 06 | 바이브 코딩 왕복 | `0 0 1000 230` | 사람 → AI → 사람. **아래로 빨간 점선 되돌림 화살표** (이게 핵심) |
| 12 | 무엇이 바뀌었나 | `0 0 1000 300` | 상단 "예전"(코딩 칸이 red warn) / 하단 "지금"(조명 칸이 blue acc). 가운데 가로 구분선 |
| 20 | 하네스는 자란다 | `0 0 1000 260` | 실패 → 적는다 → 규칙 추가 **→ 순환해서 실패로 되돌아가는 초록 폐곡선** |
| 22a | 순서 짜기 | `0 0 420 190` | 계획 → 검토 3개 병렬 → 종합. 분기·합류 |
| 23 | 다섯이 맞물린다 | `0 0 1000 300` | 하단에 초록 하네스 바(전폭) · 지휘→일꾼→루프 · 루프 회귀선(보라) · 훅 판정선(초록 점선) |
| 26 | 통행권 | `0 0 1000 240` | 명령 → **게이트 박스(8단계 텍스트)** → 전송. 하단에 빨간 점선 "우회 불가" 표시 |
| 29 | 번호 ≠ 주소 | `0 0 1000 210` | 2행 대비. 위=1 → 빨간 화살표 → "오류 없음, 엉뚱한 조명" / 아래=101 → 초록 → "의도한 조명" |

> **모든 `<svg>`에 `role="img"` + 서술형 `aria-label` 필수.** 다이어그램이 정보의 본체라 대체 텍스트가 없으면 접근성이 아니라 내용이 사라진다. 원본 파일의 aria-label 문구를 그대로 쓴다.

## 6. 검수 체크리스트

Claude Design 결과물을 받았을 때 이 순서로 본다.

**형식**
- [ ] 34장 전부 정확히 16:9인가 (오차 2% 이내)
- [ ] 내용이 슬라이드 밖으로 넘친 장이 하나도 없는가 (`scrollHeight > clientHeight` 0건)
- [ ] 가로 스크롤이 생기지 않는가 (`body.scrollWidth === innerWidth`)
- [ ] 인쇄 미리보기에서 1슬라이드 = 1페이지(가로)인가
- [ ] 발표자 노트가 인쇄에서 빠지는가

**한글 조판**
- [ ] `word-break: keep-all`이 적용돼 어절 중간에서 안 끊기는가
- [ ] 제목에 `text-wrap: balance`가 걸려 줄 길이가 고르게 나뉘는가
- [ ] 한글 폰트가 SF로 폴백되지 않고 Apple SD Gothic Neo / Pretendard로 잡히는가

**색 · 접근성**
- [ ] 모듈 레일 색이 §1-2 배정과 어긋나지 않는가
- [ ] 한 슬라이드에 주 강조색이 3개 이상 쓰이지 않았는가
- [ ] 본문(`--lb-2`)이 `#000` 위에서 대비 4.5:1을 넘는가
- [ ] 모든 다이어그램 SVG에 `role="img"` + `aria-label`이 있는가
- [ ] 노트 토글 버튼에 키보드 포커스 링이 보이는가

**내용**
- [ ] 숫자가 원본과 일치하는가 — 443 · 17 · 131 · 10 · 63 · 28 · 25 · 3주 · 1명
- [ ] 새 용어가 일상어 설명 **뒤에** 나오는가 (순서가 뒤집히지 않았는가)
- [ ] 시간 예측 표현이 없는가
- [ ] 실패 사례 2장(28·29)이 성공 슬라이드보다 약해 보이지 않는가
