# 용어 사전 — 일상어로 풀어쓰기

> 이 과정에는 **두 세계의 용어**가 섞여 나온다. 조명 쪽 말과 컴퓨터 쪽 말이다.
> 조명 전공생은 오른쪽이 어렵고, 컴퓨터를 아는 사람은 왼쪽이 어렵다. **둘 다 여기 있다.**
>
> **강사에게**: 첫 회차에 이 사전을 인쇄해 나눠준다. 수업 중 새 용어가 나오면 "몇 번 보세요"로 넘긴다.

---

## A. 조명 용어 — 컴퓨터 쪽 사람에게

| 용어 | 일상어로 하면 |
|---|---|
| **콘솔** | 조명을 조작하는 큰 조종대. 무대 뒤나 객석 뒤에 있는 그 기계 |
| **grandMA3 (MA3)** | 콘솔 제품 이름 중 하나. 공연장에서 가장 널리 쓰이는 축에 든다 |
| **onPC** | 그 콘솔을 **일반 컴퓨터에서 돌리는 프로그램**. 무료다. 진짜 조명은 못 켜지만 연습·설계는 다 된다 |
| **리그(rig)** | 무대에 매달아 놓은 조명 장비 **전체**. "이번 리그는 무빙 20대" 처럼 쓴다 |
| **픽스처(fixture)** | 조명 기구 **한 대**. 전구 하나가 아니라 장비 하나 |
| **무빙(moving light)** | 방향·색·모양이 바뀌는 조명 기구. 고정된 것과 달리 움직인다 |
| **패치(patch)** | 조명 기구를 콘솔에 **등록하는 일**. "이 자리에 이 장비가 있다"고 알려주는 것 |
| **DMX** | 콘솔이 조명 기구에 신호를 보내는 **표준 규격**. 조명계의 공용 언어 |
| **큐(cue)** | 저장해 둔 **조명 장면 하나**. 공연 중 순서대로 하나씩 실행한다 |
| **큐리스트** | 큐를 순서대로 늘어놓은 **목록**. 공연 대본의 조명 버전 |
| **프리셋(preset)** | 자주 쓰는 설정을 저장해 둔 것. 문서 편집기의 "서식 저장"과 같은 개념 |
| **실행기(executor)** | 큐를 실행하는 **버튼이나 페이더 자리**. 콘솔에 여러 개 있다 |
| **페이더(fader)** | 위아래로 미는 **슬라이더**. 주로 밝기를 조절한다 |
| **그룹(group)** | 자주 같이 쓰는 조명들을 **묶어 둔 것**. "무대 앞줄 8대" 같은 |
| **룩(look)** | 완성된 **한 장면의 조명 그림**. "따뜻한 저녁 느낌" 같은 것 |
| **이펙트(effect)** | 자동으로 반복되는 움직임이나 색 변화. 물결·회전·깜빡임 같은 것 |
| **쇼파일(showfile)** | 공연 하나의 **모든 설정이 담긴 파일**. 이게 날아가면 처음부터 다시 |
| **버스킹(busking)** | 미리 짜두지 않고 **즉석에서** 조명을 운용하는 것. 재즈의 즉흥연주 같은 |
| **포커싱(focusing)** | 조명이 정확한 위치를 비추도록 **맞추는 작업** |
| **프리비즈(previz)** | 실제 장비 없이 **컴퓨터 화면으로 미리 보는 것** |

## B. AI · 컴퓨터 용어 — 조명 쪽 사람에게

### B-1. 가장 먼저 알아야 할 것

| 용어 | 일상어로 하면 |
|---|---|
| **바이브 코딩** | 코드를 직접 타이핑하지 않고, **원하는 걸 말로 설명해서** AI가 만들게 하는 방식 |
| **AI 모델** | 대화하고 글을 쓰는 **AI 그 자체**. Claude, Gemini, GPT 같은 것들 |
| **터미널** | 컴퓨터에 **글자로 명령을 입력하는 창**. 마우스 없이 키보드로만 쓴다 |
| **CLI** | 터미널에서 쓰는 프로그램. "Command Line Interface"의 줄임말 — **글자로 조작하는 프로그램** |
| **컨텍스트(context)** | AI가 **지금 기억하고 있는 내용 전부**. 사람으로 치면 머릿속에 들고 있는 것 |
| **컨텍스트 창** | 그 기억의 **최대 용량**. 넘치면 앞부분을 잊는다 |
| **토큰(token)** | AI가 글을 세는 단위. 한글 한 글자쯤. **비용이 이 단위로 계산된다** |
| **프롬프트(prompt)** | AI에게 **주는 지시문**. "이렇게 해줘"라고 쓴 내용 |

### B-2. 이 과정의 핵심 5개 (M5에서 자세히)

| 용어 | 일상어로 하면 | 비유 |
|---|---|---|
| **오케스트레이션** | 혼자 다 하지 않고 **여러 AI에게 역할을 나눠주고 결과를 모으는 것** | 조별과제의 조장이 하는 일 |
| **에이전트 / 서브에이전트** | **역할과 권한이 정해진 AI 한 명**. 각자 자기 기억만 갖는다 | 조별과제의 팀원. 각자 맡은 것만 한다 |
| **하네스(harness)** | AI가 일할 때의 **규칙 모음 + 자동 검사 장치** | 실습실 안전수칙 + 기계의 안전 커버<br>*원래 뜻은 말에 씌우는 마구(고삐) — 힘센 걸 원하는 방향으로 몰기 위한 장치* |
| **루프(loop)** | 조건을 정해두고 **그게 될 때까지 AI가 스스로 반복**하게 하는 것 | "다 될 때까지 계속" — 단, 언제 그만둘지도 같이 정해야 한다 |
| **그래프 엔지니어링** | **순서 짜기**(뭘 동시에, 뭘 차례로) + **기억 관리**(뭘 언제 읽힐지) | 지하철 노선도처럼 점과 선으로 그린 관계도 |

### B-3. 자주 나오는 나머지

| 용어 | 일상어로 하면 |
|---|---|
| **훅(hook)** | **특정 순간에 자동으로 켜지는 검사.** "저장할 때마다 맞춤법 검사" 같은 것<br>*원래 뜻은 갈고리 — 특정 시점에 걸어두는 것* |
| **스킬(skill)** | AI가 **필요할 때 꺼내 읽는 전문 지식 묶음**. 참고서를 선반에 꽂아둔 것 |
| **플러그인(plugin)** | 기능을 **끼워 넣는 부품**. 규칙·지식·검사를 한 묶음으로 배포한 것 |
| **MCP** | AI가 다른 프로그램과 연결되는 **공통 규격**. **USB 같은 것** — 규격이 같으면 아무거나 꽂힌다 |
| **API** | 프로그램끼리 **주고받는 창구**. 식당의 주문 창구를 생각하면 된다 |
| **OSC** | 네트워크로 명령을 보내는 **약속된 방식**. 이 프로젝트가 콘솔에 말을 걸 때 쓴다 |
| **샌드박스(sandbox)** | AI가 **놀 수 있는 울타리**. 안에서 뭘 해도 밖은 안 망가진다 |
| **권한(permission)** | AI가 **할 수 있는 일의 범위**. 읽기만 되게 할 수도, 쓰기까지 되게 할 수도 있다 |
| **테스트(test)** | 코드가 제대로 도는지 확인하는 **자동 점검표**. 사람이 매번 눌러보지 않아도 된다 |
| **회귀 테스트** | 뭘 고치다가 **다른 데가 망가졌는지** 확인하는 검사 |
| **린트(lint)** | 문법·스타일을 **자동으로 잡아주는 검사기**. 맞춤법 검사기의 코드 버전 |
| **커밋(commit)** | 작업 내용을 **저장 지점으로 찍어두는 것**. 게임의 세이브 포인트 |
| **깃(git) / 리포지토리** | 변경 이력을 **전부 기억하는 폴더**. 언제든 과거로 돌아갈 수 있다 |
| **CI** | 코드를 올릴 때마다 **자동으로 검사해 주는 서버** |
| **헤드리스(headless)** | 화면 없이 **명령만으로 실행**하는 것 |
| **Lua** | 간단한 **프로그래밍 언어**. 이 프로젝트에선 콘솔 **안에서** 도는 코드를 이걸로 쓴다 |
| **파이썬(Python)** | 널리 쓰이는 프로그래밍 언어. 이 프로젝트의 **컴퓨터 쪽** 코드가 이걸로 돼 있다 |
| **XML** | 정해진 형식으로 적은 **설정 파일** 형식 |
| **파싱(parsing)** | 파일을 읽어서 **의미를 뽑아내는 것** |
| **프로바이더 추상화** | **AI를 갈아끼우기 쉽게** 만들어두는 설계<br>*전구 소켓과 같다 — 규격이 맞으면 어느 회사 전구든 끼워진다* |
| **비목표(non-goal)** | **일부러 안 하기로 정한 것.** 계획서에 명시해 둔다 |
| **인수 기준** | **"다 됐다"고 인정하는 기준.** 미리 정해두지 않으면 아무도 판정 못 한다 |
| **SPEC** | **계획 문서**. 무엇을 / 안 할 것 / 완료 기준을 적어둔 것 |
| **MVR · GDTF** | 조명 장비와 배치 정보를 담는 **표준 파일 형식**. 도면 프로그램과 콘솔이 주고받는다 |

## C. 헷갈리기 쉬운 짝

학생들이 가장 자주 섞어 쓰는 것들이다. **첫 회차에 짚고 넘어간다.**

| 이것 ≠ 저것 | 차이 |
|---|---|
| **개발 도구** ≠ **런타임 모델** | 내가 도구를 **만들 때** 쓰는 것 vs 만든 앱 **안에서 도는** 것 (M2-1) |
| **조회** ≠ **조작** | 읽을 수 있다고 시킬 수 있는 건 아니다 (M4-5) |
| **`ok`** ≠ **증거** | "됐습니다"는 주장이다. 증거는 **다시 확인한 결과** (M4-5) |
| **`0`** ≠ **비었음** | "0개"가 "이 방법으로는 안 보인다"일 수 있다 (M4-5 Case C) |
| **부품 검사** ≠ **완성품 검사** | 부품이 다 멀쩡해도 조립이 틀릴 수 있다 (M3-6) |
| **에이전트** ≠ **AI 모델** | 역할이 정해진 **일꾼 한 명** vs **AI 자체** |
| **훅** ≠ **스킬** | 자동으로 켜지는 **검사** vs 필요할 때 꺼내 읽는 **지식** |

## D. 이 사전을 쓰는 법

**수강생에게**
- 모르는 말이 나오면 **바로 손 들어라.** 이 사전에 없는 말이면 강사가 추가한다
- 처음부터 다 외우지 않는다. **나올 때마다 찾아본다**

**강사에게**
- 새 용어를 쓸 때는 **일상어 설명을 먼저** 하고 용어를 뒤에 붙인다
  - ✅ "AI가 지금 기억하고 있는 내용 — 이걸 **컨텍스트**라고 합니다"
  - ❌ "컨텍스트가 부족하면 앞을 잊습니다"
- 이 사전은 **기수마다 자란다.** 수강생이 막힌 단어를 계속 추가하라
