R1main은 PR로만 자란다 — 직접 커밋 금지

모든 작업은 main에서 딴 브랜치에서, 스위트 그린 확인 후 PR 머지로만 합류.

git checkout -b jjjh7401/<작업명> origin/main   # 시작
gh pr create → gh pr merge                      # 합류

R2머지된 브랜치는 즉시 삭제 — 로컬·원격 모두

git branch -d(안전 삭제 — 미머지면 거부)라 실수로 잃을 일이 없다.

근거: 이번 혼란의 시작이 머지 완료된 MAcopilotartifacts가 워크트리째 남아 있던 것.
git branch -d <브랜치> && git push origin --delete <브랜치>
