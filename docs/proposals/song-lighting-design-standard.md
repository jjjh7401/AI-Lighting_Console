# 곡 단위 조명연출 표준 초안 (Song Lighting Design Standard, v0.2)

> SPEC-COPILOT-SONGSTD-001의 1단계 산출물. 근거는
> `.moai/specs/SPEC-COPILOT-SONGSTD-001/research.md` (출처 포함 80+ 사실,
> 웹 3방향 + 리포 능력 전수조사). 목적: "효과의 나열"이 아니라 **조명감독이
> 타임라인 위에서 내리는 판단**을 기계 검사 가능한 규칙으로 옮긴다.
> 이 표준이 서면 컬러×포지션 통합·TrigTime 자동 진행은 이 표준의 구현체가 된다.

## 0. 철학 (규칙의 뿌리)

1. **조명은 곡의 구두점이다** — 곡을 보완하지 압도하지 않는다. 모든 큐는
   음악적 사건(구간 경계·히트·다운비트)에 대응해야 하고, 음악적 근거가
   없는 변화는 넣지 않는다.
2. **긴장-해소 모델** — 벌스는 긴장을 쌓고, 프리코러스는 변화를 예고하고,
   코러스는 해소한다. 조명의 에너지는 이 곡선을 따라간다.
3. **헤드룸 보존** — 항상 최대치면 최대치가 없다. 클라이맥스를 위해
   시각적 여유(밝기·속도·색·이펙트 밀도)를 아껴둔다.
4. **하나의 완벽한 아이디어 > 싸우는 다섯 아이디어** — 축을 늘리는 것이
   아니라 판단을 늘리는 것이 연출이다.

## 1. 설계 절차 (LD 워크플로 — 시스템의 파이프라인 순서)

| 단계 | 행위 | 시스템 대응 |
|---|---|---|
| P1 | 곡 구조 분석: 구간 경계(intro/verse/pre/chorus/bridge/solo/breakdown/outro)와 시각, BPM | 입력 스키마 (구간+시각+BPM) |
| P2 | 구간별 다이내믹스 D1~D5 부여 + 곡의 감정색 결정 | 다이내믹스 추론·확인 카드 |
| P3 | **기본 룩 4~5개** 설계 (오프닝/벌스/코러스/솔로/엔딩) — 각 룩 = 전 축의 묶음 | 룩 = 포지션 프리셋 + 팔레트 + 디머층 + 이펙트 |
| P4 | 타임라인에 큐 배치: 구간당 최소 1큐 + 악센트 큐(히트/버튼) | 큐 시트 생성 (구간=정수 번호, 삽입=소수) |
| P5 | 전환 타이밍·MIB·트리거 결정 | CueFade/Follow/TrigTime |
| P6 | 린트(§9) → 위반 카드 → 운영자 승인 → 콘솔 저장 | 자동 검사 |

## 2. 타임라인 문법

- **T1. 구간당 최소 1큐.** 큐 없는 구간은 위반(의도적 유지면 명시 태그).
- **T2. 큐 번호 = 구간 순번(정수).** 악센트·MIB 등 삽입 큐는 소수(k.5).
  구간 대역을 띄우는 연극식(100/200) 규약은 다곡 셋리스트에서 곡당 대역으로
  적용한다.
- **T3. 악센트 큐는 다운비트에 정렬.** 히트/범프/버튼은 마디 1박. BPM이
  주어지면 악센트 시각은 비트 격자에 스냅한다.
- **T4. 곡의 끝은 "버튼" 또는 페이드아웃 중 하나로 명시.** 버튼 = 0~0.5s
  급점등 후 유지→다운. 페이드아웃 = 3~5s 이상.
- **T5. 실행 모드는 하이브리드가 기본.** 구간 전환·드롭 = 시퀀스 큐
  (타임코드/TrigTime 가능), 순간 액션(스트로브·블라인더·오디언스 스윕) =
  수동 트리거로 분리 설계. 전곡 타임코드 강제는 기본값이 아니다.

## 2b. 음악 프로파일 계층 — 모든 규칙의 파라미터는 음악에서 온다 (v0.2)

표준의 수치는 고정 상수가 아니라 곡의 음악적 신원이 채우는 변수다.
음악 프로파일 = **장르 · 템포(BPM) · 박자 · 조성/모드 · 컨셉 · 구간 분위기 ·
악센트**. 각 속성의 바인딩:

| 음악 속성 | 움직이는 규칙 | 바인딩 |
|---|---|---|
| 템포 (BPM) | 모든 시간 값 (§3 페이드, §4d Speed, V3 정체 한계, G1~G3) | 시간은 **박/마디 단위로 정의**, BPM이 초로 환산. `1박 = 60/BPM 초` |
| 박자 (4/4 등) | T3 다운비트 격자, 마디 환산 | 악센트 스냅 격자 |
| 장르 | §7 프로파일 → §3 표 기본값 오버라이드, 질감(스냅/페이드), 팔레트 시드, 이펙트 어휘 허용치 | 같은 D4라도 메탈=스냅+레드, 하우스=페이드+유사색 |
| 조성/모드 (장/단조) | 팔레트 웜/쿨 성향, 채도 상한 (C4) | 단조·어두움 → 쿨·저채도 바이어스 |
| 컨셉/세계관 | 팔레트 선언(C1)·포지션 선택 바이어스(P계열) | 컨셉 어휘 → 시드: "우주"=블루/퍼플+Ring In, "네온"=마젠타/시안+Cross, "빈티지"=웜 CTO+Wall 등 (확장 가능한 시드 표) |
| 구간 분위기 (무드어) | D레벨 추론 + 색 의미론 (기존 무드 매핑 확장) | 무드어 → (D, 색 성향) 쌍 |
| 악센트 (히트·드롭·버튼) | 소수 삽입 큐 + 스냅 허용 위치 (L9) | 다운비트 격자에 스냅 |

- **M1. 시간의 기저는 박이다.** §3·§6의 초 표기는 120 BPM 4/4 기준 환산
  예시다. 엔진은 박 단위 원본 값(아래 §3 표의 괄호)을 쓰고 BPM으로 환산한다.
- **M2. 우선순위: 구간 분위기 > 컨셉 > 장르 > 전역 기본값.** 충돌 시
  구체적인 쪽이 이긴다 (예: 메탈 곡의 발라드 브릿지는 브릿지 무드가 우선).
- **M3. 입력 충실도 3단계.**
  - F1 텍스트 브리프(구간+무드어): 장르·BPM은 질문 카드로 보충.
  - F2 브리프+메타(BPM·장르·컨셉 명시): 표준 완전 동작. 현 시스템 목표.
  - F3 오디오 분석(장래): BPM·온셋(악센트 후보)·RMS 에너지 곡선(D 자동
    추론)·구간 경계 추출. 단 **분위기·컨셉 판단은 자동화하지 않고 카드
    확인** — 연출 판단은 사람 몫(기존 무드 제안 관례와 동형).
- **M4. 무드어 → (D, 색) 통합 사전.** 기존 position_moods와 별개가 아니라
  한 사전이 D레벨·색 성향·포지션 후보를 함께 낸다 (예: "웅장한 피날레" →
  D5 + 쿨 볼드 + Ring In; "잔잔한 발라드" → D2 + 블루/웜화이트 + Vocal DSC).

## 3. 에너지 모델 — 다이내믹스 D1~D5가 전 축을 함께 결정

현 시스템의 결함: 다이내믹스가 룩 선택 인덱스에 불과해 벌스와 후렴의
디머가 같다(실측: Seq 114 전 큐 100%). 이 표는 그것을 고친다.
**D레벨은 모든 축의 예산이다:**

| 축 | D1 (앰비언트) | D2 (벌스) | D3 (프리코러스/빌드) | D4 (코러스) | D5 (클라이맥스) |
|---|---|---|---|---|---|
| 디머(키층 기준 %) | 20~40 | 40~60 | 60~80 | 80~100 | 100 (+블라인더 후보) |
| 페이드 인 (박 기준) | 2마디 (8박; 120bpm≈4s) | 1마디 (4박; ≈2s) | 2~4박 (≈1~2s) | 1~2박 (≈0.5~1s) | 0~1박 (스냅 허용) |
| 포지션 폭 | 좁음 (Vocal DSC/Center) | 좁음~중간 | 중간 (Wall/Fan In) | 넓음 (Fan Out/Cross) | 최대 (Audience/Ring In·Out) |
| 컬러 채도 | 낮음(파스텔·화이트 혼합) | 중간 | 중간~높음 | 높음 | 최대(단색 볼드) |
| CCT 성향 | 웜 3000~4000K | 중립 | 중립~쿨 | 쿨 5600K+ | 쿨/단색 |
| 이펙트 밀도 | 0 (정적) | 0~1축 느린 페이저 | 1축 (빌드용 점증) | 1~2축 | 2축 + 순간 액션 |
| 이펙트 속도 | — | ≤¼박 (긴 주기) | ½박~1박 | 1박 | 1~2박 (더블타임 허용) |
| 무빙(포지션 페이저) | 금지 | 금지~미세 | 스위프 진입 허용 | 허용 | 허용 (빠른 빔) |

- **E1. 디머 단조성**: 같은 곡에서 D(a) < D(b)이면 키층 디머(a) ≤ 디머(b).
  후렴이 벌스보다 어두우면 위반.
- **E2. 헤드룸 규칙**: D5 이전 구간은 디머 100%·이펙트 최대 속도·최대
  포지션 폭 셋을 동시에 쓸 수 없다 (최소 1축은 여유 보존).
- **E3. 포지션 진행**: 사람→공간, 좁음→넓음. D가 오르는 경계에서 포지션
  폭은 좁아지지 않는다 (의도적 대비 태그 예외).
- **E4. 다이내믹스는 값이다**: D레벨은 룩 인덱스가 아니라 위 표의 예산으로
  각 축 값을 실제로 스케일해야 한다.

## 4. 축별 규칙

### 4a. 인텐시티(디머) — 3층 구조
- **I1.** 층 정의: 키(프런트, 얼굴)/백(실루엣·깊이)/이펙트(빔·에어리얼).
- **I2.** 백층 = 키층의 30~50%에서 시작. 백>키는 의도적 실루엣 태그 필요.
- **I3.** 보컬 중심 구간(D1~D2, 발라드 계열)은 키층이 꺼지지 않는다 —
  "배경 화려·얼굴 암흑"은 대표적 실패.
- **I4.** 블랙아웃은 사건이다: 구간 경계의 의도적 리셋 또는 드롭 직전
  1~2박 — 곡당 예산 2~3회.

### 4b. 컬러
- **C1. 팔레트 3~5색**: 베이스 1 + 액센트 1~2 (+화이트/CTO). 곡당 고정,
  구간은 팔레트 안에서만 순환. 후렴만 +1 허용.
- **C2. 배색 전략 명시**: 보색(긴장·펀치) 또는 유사색(통일) 중 하나를
  곡 단위로 선언.
- **C3. 프런트(키층)는 중립/웜 화이트 유지** — 채도 색은 백층·이펙트층에.
- **C4. 의미론 기본값**: 벌스 쿨→코러스 웜(록), 감성=블루/퍼플, 피크=레드
  또는 곡 액센트색 볼드. 장르 프로파일(§7)이 우선.
- **C5. CCT 편차**: 동시 점등 화이트 계열은 ±500K 이내(방송 병행 ±300K).

### 4c. 포지션 (기존 CUETIME-001 자산 위에)
- **P1.** 큐는 반드시 Position 프리셋 참조(재계측 없이 전 큐 추종 — 검증됨).
- **P2.** MIB: 디머 0 뒤 새 포지션 리빌은 다크 선이동 + `TrigType Follow`
  (실측 표준, 스킬 §3c).
- **P3.** 반복 무드는 같은 결의 대안으로 회전 (구현됨 — `_pick_varied`).
- **P4.** Audience(객석 직사)는 D5 전용 + 곡당 예산 1~2회.

### 4d. 이펙트(페이저) — 축별 용도와 속도
- **F1. 축별 용도표**: 무빙 스위프/서클=기악·빌드(벌스 금지), 디머
  체이스·펄스=리듬 강조(D3+), 컬러 체이스=질감(D3+), 줌 브리딩=호흡(D2+
  느리게), 고보/프리즘=순간 어트리뷰트 큐(상시 금지 — 현 콘솔 스코프 밖).
- **F2. 속도는 BPM의 배수**: Speed는 곡 BPM에 정렬. 빠른 축(디머·컬러)
  = 1박/스텝, 느린 축(포지션·줌) = 4~8박 주기 — 배수 관계 유지.
- **F3. 동시 이펙트 축 수 = D레벨 예산**(§3 표). 전 축 동시 구동 금지.
- **F4. 스냅 vs 페이드 질감은 장르가 결정** (테크노=하드, 하우스=소프트).
- **F5. 진폭 절제**: 포지션 페이저 진폭은 룩을 깨지 않는 범위(±30° 이내,
  현 라이브러리 관례)로. 빠른 풀레인지 디머 펄스(플래시)는 배제 정책 유지.

### 4e. 순간 액션 (스트로브·블라인더) — 예산과 안전
- **X1. 최고점 예산**: 블라인더/풀 화이트 히트는 곡당 1~2회, 위치는
  마지막 코러스·엔딩·최대 드롭에 한정. 어두운 구간 직후가 가장 강력하다.
- **X2. 스트로브는 구두점**: 짧은 버스트(≤수 초), 연속 ≤30초, 주파수는
  발작 위험 대역(10~25Hz) 회피 — 공연 권고 ≤4Hz. 현 콘솔 정책상 스트로브
  축은 배제되어 있으므로 **이 규칙은 장래 계층**이다(§10).
- **X3. 순간 액션은 시퀀스 큐가 아니라 수동 트리거 설계가 기본**(§2 T5).

## 5. 대비·변화율 규칙 (타임라인 전체를 보는 눈)

- **V1. 인접 큐 변화율**: 연속 큐 사이에 크게 바뀌는 축은 1~2개
  (포지션이 바뀌면 팔레트는 유지). 전 축 동시 변경은 구간 리셋(D 급변
  ≥2 또는 블랙아웃 경유)에서만.
- **V2. 반복 회피**: 동일 (포지션, 팔레트, 이펙트) 3중 조합의 연속 큐 금지.
  같은 무드 재등장은 대안 회전.
- **V3. 정체 회피**: 동일 룩 유지가 24박(또는 20초)을 넘으면 미세 변화
  (줌 브리딩·컬러 시프트·인텐시티 웨이브) 1축 권장 — D1 앰비언트는 예외.
- **V4. 피크 유일성**: 곡 전체에서 §3 표의 D5 전축 최대는 1회 —
  진짜 클라이맥스에만.

## 6. 전환 타이밍 규칙

- **G1.** 스냅(0s)은 히트/드롭/버튼 한정. 구간 전환 기본은 1.5~2s,
  빌드·감정 전환은 3~5s, 발라드 계열은 5s+ 허용.
- **G2.** D 상승 전환은 짧게(에너지 진입), D 하강 전환은 길게(여운) —
  기본 비대칭.
- **G3.** MIB 선이동은 1s + Follow (실측 표준).
- **G4.** TrigTime 자동 진행은 §2 T5의 하이브리드 원칙 안에서만 —
  구간 경계 큐에 적용, 순간 액션에는 적용하지 않는다.

## 7. 장르 프로파일 (기본값 오버레이)

| 장르 | 팔레트 | 질감 | 특징 규칙 |
|---|---|---|---|
| 메탈 | 스래시=레드/웜, 블랙=콜드블루/화이트, 파워=비비드 | 스냅 위주, 더블킥×디머 체이스 동기 | 대비 우선, 블랙아웃→급점등 관례 |
| 록 | 레드+화이트 시그니처, 웜/쿨 대비 | 히트 정밀 타이밍 | 같은 곡 내 웜↔쿨 전환이 다이내믹스 표현 |
| EDM | 단색 볼드, 퍼플/레드/화이트 | 하드 스냅, 기하학 | 드롭=순간 액션 집중, 빌드=속도 점증 |
| 발라드 | 블루/퍼플 백 + 소프트 화이트 프런트 | 긴 페이드(5s+) | 무빙 최소, 키층 상시 유지, 엔딩 타이트 스팟→페이드투블랙 |
| 팝 | 유사색 3~4 + 액센트 1 | 중간 | 후렴 팔레트 +1 활용 |

## 8. 입력 계약 — 곡 설계 명세 (design brief)

음악 프로파일(§2b)이 곧 입력 스키마다:

```
곡:   제목, 장르, BPM [, 박자=4/4] [, 조성/모드] [, 컨셉 어휘]
      [, 팔레트 선언 (베이스+액센트 / 배색 전략)]
구간: 이름 + 시각 + 무드어 (또는 D1~5 직접 지정)  ×N
악센트: 히트/드롭/버튼 시각 목록 (선택)
```

- 필수는 구간 목록뿐이다(F1). BPM·장르가 없으면 질문 카드로 보충하고,
  없는 채 진행하면 시간 규칙은 120 BPM 기본값으로 환산하되 그 사실을
  결과에 명시한다.
- 다이내믹스·팔레트를 직접 주지 않으면 무드어·컨셉·장르에서 추론 후
  **카드로 확인** (단정 실행 금지 — 기존 무드 제안 관례 유지).
- F3(오디오 분석)이 열리면 BPM·구간 경계·악센트·에너지 곡선이 파일에서
  자동 제안되고, 같은 카드 확인 절차를 거친다.

## 9. 기계 검사 규칙 (린트 L1~L14)

시트 초안은 저장 전 다음을 검사하고 위반을 카드로 보고한다:

| # | 검사 | 근거 |
|---|---|---|
| L1 | 구간당 큐 ≥1 | T1 |
| L2 | D 단조성: D↑인데 키층 디머↓ | E1 |
| L3 | 헤드룸: D5 이전 전축 최대 동시 사용 | E2, V4 |
| L4 | 포지션 폭이 D 상승 경계에서 축소 (태그 없이) | E3 |
| L5 | 팔레트 크기 > 5 또는 곡 중 팔레트 이탈 | C1 |
| L6 | 키층 소등 + 보컬 구간 (D1~D2) | I3 |
| L7 | 백층 > 키층 (실루엣 태그 없이) | I2 |
| L8 | 블랙아웃 > 3회 | I4 |
| L9 | 스냅(0s)이 히트/드롭/버튼 외 위치 | G1 |
| L10 | 동시 이펙트 축 수 > D레벨 예산 | F3 |
| L11 | 이펙트 Speed가 BPM 배수 격자 밖 (±10%) | F2 |
| L12 | 인접 큐 변화 축 > 2 (리셋 아님) | V1 |
| L13 | 동일 3중 조합 연속 | V2 |
| L14 | Audience/블라인더 예산 초과 (>2회) 또는 D5 외 사용 | P4, X1 |

린트는 **차단이 아니라 보고**다 — 연출은 규칙을 의도적으로 깰 수 있고,
그 결정은 운영자가 카드에서 내린다 (기존 승인 관례와 동형).
