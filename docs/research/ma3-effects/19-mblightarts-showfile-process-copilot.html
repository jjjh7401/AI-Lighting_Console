02

전체 프로세스

핵심은 새 쇼를 빈 파일에서 만드는 것이 아니라, 검증된 템플릿 객체 구조를 실제 리그에 맞게 재연결하는 것입니다.

1. Inventoryfixture category, truss/floor 위치, DMX, mode 파악
2. Patch템플릿 fixture 유지/교체/삭제, ID range 정리
3. Group Gridsimrik group을 실제 무대처럼 2D grid에 배치
4. Presetsposition, gobo, prism, strobe, zoom, color 보정
5. GenerateMaster macro, layout, executor, recipe cook 검증

조명감독의 판단 영역

fixture orientation, 실제 조준, 색상 출력 균형, audience blind/strobe 안전성, busking 중 손이 가는 executor 배치는 사람이 봐야 합니다.

Copilot의 강점

객체 누락 점검, grid/preset/recipe 계획, pool 충돌 확인, matrix block 계산, cook 필요 여부 판단, 실행 후 검증 checklist 생성에 적합합니다.

04

2D Selection Grid

simrik group은 이 showfile의 중심 객체입니다. 대칭 effect, color recipe, delay sweep, rig FX가 모두 이 grid를 신뢰합니다.

Grid가 맞아야 효과가 맞습니다

좌우 순서, row 구성, 중앙축, gap 유지 여부가 horizontal chase, odd/even, center-out, circular wave의 모양을 결정합니다.

저장 성공과 룩 성공은 다릅니다

잘못된 grid에서도 sequence와 recipe는 저장됩니다. 하지만 무대에서는 방향이 뒤집히거나 중심이 어긋난 룩이 나옵니다.

08

Auto Position

Auto positioning은 첫 두 기준 preset을 사람이 만든 뒤 macro가 나머지 fan/cross/variant position을 생성하는 방식입니다.

필수 기준 preset

straight down과 straight up은 Pan 없이 직선 방향으로 조준한 Tilt 기준입니다. 이 두 값이 틀리면 생성 position 전체가 틀어집니다.

Macro 생성 방식

Auto pos main macro가 개별 position macro를 호출하고, macro 내부는 group 선택, align, MAtricks, Pan manipulation으로 구성됩니다.

Copilot 안전 원칙

기준 position 조준은 자동화하지 않습니다. Copilot은 기준 preset 누락, macro 실행 계획, 생성 후 visual checklist까지만 책임집니다.

Simple Chaser

Block Chaser

Left-RightX Block

Delay Sweep

상세 콘솔 Runbook

Copilot이 실제 조작 안내로 바꿀 수 있도록 영상별 버튼, 화면, macro, executor, recipe editor 경로를 더 구체화했습니다.

초기 템플릿 적응: Patch → Groups → Presets → Master

순서콘솔 조작Copilot이 기록할 객체
1Patch menu를 열고 기존 템플릿 fixture를 실제 fixture type으로 교체하거나 새로 insert한다. 필요 없는 fixture는 unpatch/delete한다.Fixture, FixtureType, Universe, fixture ID range
2patch 후 Save and Exit한다. position이 반대로 보이면 preset 수정 전 Pan/Tilt invert를 확인한다.PatchOrientationCheck
3Groups view에서 fixture type마다 main simrik group을 만든다. 실제 stage row에 맞춰 2D selection grid에 fixture를 배치한다.Group, Selection Grid, row/column mapping
4spot 예시는 front truss 1101 thru 1108 선택 후 다음 grid row에서 mid truss 1201 thru 1208 선택, group에 Store/Overwrite.GroupLayoutPlan
5pixel tube는 master fixture group과 sub-fixture simrik group을 분리한다. 16×8이면 Grid 0/0 thru 15/7처럼 영역을 만들고 필요 시 90도 transform한다.pixel master group, sub-fixture group, transform flag
6Presets section에서 fixture category별 macro button으로 view를 전환하며 position, gobo/global, prism, strobe, zoom, color preset을 보정한다.PresetBootstrapPlan, pool slot, store policy
7Macro view → Global → Master macro 실행. Color Picker popup은 기본값 유지 후 reinstall → generate → confirm.ShowfileRegenerationPlan, plugin step

Layout A/B 세부 기능

  • Layout A top-left: moving group별 position button.
  • Layout A position 아래: movement/position FX button.
  • Layout A upper-right: fixture category별 Color Picker.
  • Color Picker 아래: intensity FX 또는 color FX form.
  • Layout B: gobo, prism, zoom, tap chaser, override, rig FX.
  • Hardware layout: Group Master, flash/color bump, strobe, random strobe, tap executor, temp/size fader.

Global macro와 X-key

  • Switch to Console / Command Wing: screen/hardware layout 전환.
  • Reset Show File: running sequence kill. 공연 중 사용 주의.
  • Initial File: 필요한 sequence restart.
  • Master time 0-5s: color/position transition fade time 설정.
  • Master FX Off: running FX 비활성화.
  • Break / Release: FX를 pause했다가 다른 look으로 release 가능.
