01

한눈에 보기

Positions의 핵심은 기준 포지션 보정값을 이용해 Pan/Tilt 조합을 대량 생성하는 것입니다.

핵심 요약

공개 설명상 Positions는 몇 개의 calibrated reference positions를 기준으로 6 Tilt × 30 Pan, 최대 180개의 매칭 Position Preset을 생성합니다. Copilot은 이를 그대로 복제하기보다 calibration runbook, position grid plan, pool collision guard, Store Offset 안내로 나눠 구현해야 합니다.

  • Calibration이 정확해야 모든 생성 결과가 맞습니다.
  • Programmer Mode는 미리보기/부분 선택에 적합합니다.
  • Preset Mode는 pool write가 있는 대량 생성이므로 충돌 가드가 필요합니다.

03

워크플로우

공개 매뉴얼의 기능을 Copilot 관점으로 다시 나누면 다음 네 덩어리입니다.

Calibration

ReferenceApply Position

픽토그램이 지시하는 위치로 조명을 실제 무대에서 맞추고 기준값을 저장합니다. 새 fixture type마다 필요합니다.

Programmer Mode

PreviewPartial Selection

현재 선택된 fixture만 대상으로 Pan/Tilt 조합을 Programmer에 올립니다. 자동 저장하지 않아 비교적 안전합니다.

Preset Mode

Batch StorePreset Pool

Group Pool의 전체 그룹에 대해 선택한 Tilt/Pan 조합을 Position Preset Pool에 직접 생성합니다.

Merge / Duplicate

MergeDuplicate

기존 preset에 새 fixture 값을 합칠지, 같은 조합을 새 preset set으로 따로 만들지 결정합니다.

Middle Mode

Odd CountSymmetry

fixture 수가 홀수일 때 중앙 기준 대칭 계산을 더 좋게 만드는 설정으로 공개 설명에 등장합니다.

Store Offset

ToleranceCorrection

설치 공차로 일부 장비가 어긋나면 generated preset을 덮기보다 Store Offset workflow로 보정합니다.

04

제한사항

Copilot에 넣을 때 가장 중요한 안전 조건입니다.

같은 물리 방향만 함께 처리

X/Y/Z 축으로 서로 회전된 fixture, upside down, 90도 회전 설치, pan/tilt orientation이 다른 fixture는 한 번에 자동 생성하지 않습니다. truss별 또는 orientation group별로 나눠야 합니다.

잘못된 Calibration은 전체 결과를 망칩니다

매뉴얼의 troubleshooting도 먼저 calibration positions를 검증하라고 안내합니다. Copilot도 대량 생성 전 대표 기준 포지션 검증을 요구해야 합니다.

05

Copilot 연동 모델

포지션 프리셋 요청은 아래 구조화 객체로 들어와야 콘솔 연결이 명확해집니다.

1. 요청 해석포지션팩, 팬/틸트 조합, 대상 그룹
2. 대상 분리fixture type, truss, orientation group
3. 보정 확인CalibrationProfile 존재/검증
4. 저장 가드Preset Pool, Merge/Duplicate, 충돌 확인
{
  "intent": "create_position_presets",
  "target": {
    "group_label": "MOVER-U",
    "fixture_type": "moving_profile",
    "orientation_group": "upstage_truss_same_orientation"
  },
  "calibration": { "profile_id": "MOVER-U-default", "required": true, "status": "verified" },
  "grid": {
    "tilt_positions": ["near", "mid", "far"],
    "pan_positions": ["SL", "CSL", "C", "CSR", "SR"],
    "middle_mode": false
  },
  "mode": "preset",
  "store": { "destination": "position_preset_pool", "start_slot": "next_free", "policy": "duplicate" },
  "safety": { "same_orientation_only": true, "allow_overwrite": false }
}
06

콘솔 연결 방식

Copilot은 Programmer Mode와 Preset Mode를 분리해서 구현해야 합니다.

모드콘솔 대상Copilot 행동주의
Programmer Mode현재 선택 fixture / Programmer계산 또는 호출한 position 값을 Programmer에 올리고 저장 여부를 사용자에게 맡김자동 pool write 없음
Preset ModeGroup Pool / Position Preset PoolTilt × Pan 조합 수, 시작 slot, merge/duplicate policy를 확인 후 대량 저장pool 충돌과 기존 cue 참조 확인
CalibrationPosition attribute / reference profile기준 위치를 순서대로 안내하고 사용자가 조준한 값을 저장operator-in-the-loop 필수
Store Offset개별 fixture pan/tilt offset생성 후 어긋난 fixture를 offset workflow로 보정 안내generated preset 직접 덮어쓰기 금지

자연어 매칭

조명감독이 말할 법한 표현과 Copilot 라우팅입니다.

"포지션 프리셋 자동으로 만들어줘"create_position_presets
"기준 포지션 보정해줘"calibrate_position_profile
"팬 5점, 틸트 3단으로"grid.pan_count=5 · grid.tilt_count=3
"선택한 장비만 프로그래머에 올려"mode=programmer
"기존 거 건드리지 말고 따로 만들어"store.policy=duplicate
"홀수 대라 가운데 기준으로 대칭"middle_mode=true

09

결론

Copilot v1의 현실적인 목표입니다.

자동 계산보다 먼저 보정과 검증

포지션 프리셋 자동화의 본질은 기준 보정값을 신뢰할 수 있게 만드는 것입니다. Calibration review 없이는 대량 생성하지 않습니다.

MAgics 계산식은 미확인

공개 자료만으로 내부 계산식은 알 수 없습니다. Copilot은 operator-guided calibration과 안전한 저장 계획부터 구현하고, Pan/Tilt 자동 계산은 별도 실측 후 확장해야 합니다.
