03

Patch

템플릿이 clone-show 구조가 아니므로 기존 patch를 모두 지우고 새 stage fixture를 넣어도 됩니다.

콘솔 조작

  • Patch menu 진입.
  • 기존 demo fixture clear/delete 가능.
  • Insert New Fixture button.
  • Library에서 전체 fixture type 검색.
  • type, mode, name, count, fixture ID, universe/address 입력.
  • confirm 후 다른 fixture type 반복.
  • fixture ID와 naming을 truss/row 단위로 재정리.
  • Save and Exit.

Copilot 처리

  • fixture list를 patch 작업 단위로 변환.
  • ID block 제안: 1101-1108, 1201-1208.
  • mode/address 누락과 충돌 검사.
  • category role과 physical location을 분리 저장.
  • 불명확한 fixture mode는 자동 확정하지 않음.

Group과 2D Selection Grid

showfile의 대칭 FX와 pixel FX는 simrik group의 selection grid를 기준으로 동작합니다.

대상Copilot 콘솔 작업감독 확인/판단
Hybrid AGroups Small view 할당. 111 thru 118 선택 후 grid 다음 row에서 1201 thru 1208. Setup Mode에서 gap을 drag/drop으로 재구성 후 store/override.Highlight + Next로 실제 stage 순서 확인.
Titan BGrid 0/0 thru 7/7 생성. 2101 thru 2108.처럼 dot-through로 sub-fixture만 선택. upper/down row 저장 후 transform/flip.pixel movement가 top-to-bottom 또는 left-to-right로 자연스러운지 확인.
X4 C simrik3101 thru 3108., 다음 row 3201 thru 3208.로 sub pixels 선택 후 simrik group 저장.8×20×2 pixel이 모두 포함됐는지 확인.
X4 C 픽셀 마스터 그룹3101 thru 3108, 3201 thru 3208처럼 dot 없이 main fixture만 선택해 픽셀 마스터 그룹 저장.fixture sheet에서 sub-fixture 번호가 선택되지 않았는지 확인.
핵심

simrik group은 pixel/intensity/color FX의 기준이고, 픽셀 마스터 그룹은 tilt, position, strobe, optics 같은 master-level feature의 기준입니다.

05

픽셀 마스터 그룹과 Dim Default

Tilt pixel bar처럼 master/sub-fixture가 나뉜 장비는 feature별 target group을 명확히 지정해야 합니다.

설정내용X4 bar 판단
Position uses 픽셀 마스터 그룹position preset/position FX가 simrik 대신 픽셀 마스터 그룹 사용켬
Strobe uses 픽셀 마스터 그룹strobe가 master fixture 기준으로 저장/실행켬
Optics/Zoom uses 픽셀 마스터 그룹zoom/iris/optics가 master fixture 기준켬
dim defaultmain dimmer default 100%, sub pixel dimmers default 0%pixel intensity FX 제어를 위해 실행
실패 증상

main dimmer가 닫혀 있거나 sub dimmer가 기본으로 열려 있으면 pixel bump와 intensity FX가 직관적으로 동작하지 않습니다.

07

Focus 3×3

Focus preset은 zoom stage 3개와 optic scenario 3개를 곱한 9개를 만들며, focus value만 저장해야 합니다.

콘솔 절차

  • group 선택, dimmer 100%.
  • optic scenario 선택: gobo open, wheel 1, wheel 2.
  • zoom stage 선택: wide, mid, narrow.
  • Clear 두 번으로 zoom 등 active record value 제거.
  • group을 다시 선택.
  • focus 값만 조정.
  • 해당 focus preset에 store.
  • 3×3 총 9개 반복.

08

Color Presets와 Regen Groups

Color preset은 simrik과 픽셀 마스터 그룹을 모두 고려해야 하므로 main groups를 재생성하고 Merge 중심으로 저장합니다.

순서작업
1showfile menu에서 regen groups icon을 실행해 category A/B/C main groups를 활성화한다.
2color preset 저장 시 all three groups를 선택하고 dimmer 100%.
3visualization 준비 단계에서는 빠르게 기본색을 저장한다. 실제 stage에서는 category별 fine tune이 필요하다.
4특정 fixture category만 선택해 색을 맞춘 뒤 Store + Merge로 기존 color preset에 추가한다.
5Merge를 쓰는 이유는 다른 category의 color information을 지우지 않기 위해서다.
09

Regen All과 Layout 검증

Preset과 color가 끝나면 regen all로 color effects, bumps, rig-size 기반 객체를 다시 생성합니다.

Regen All

showfile menu의 regen all 실행. plugin이 color effect preset과 bump를 rig size에 맞게 생성합니다.

FX Calculator

calculator icon → 수정할 running FX 선택 → wing, block, SYM group 변경. 닫으면 별도 save 없이 유지됩니다.

Feature Grid

category별 필요한 기능만 선택하고 Generate Layouts. Titan tubes는 position/optics를 숨기고, hybrid는 전체 기능을 유지합니다.

검증확인 내용
Hybrid spotsgroup master, color, position, gobo/zoom, CFX가 동작하는지 확인.
Tilt barsintensity FX가 pixel elements에서 대칭적으로 보이는지 확인.
Alternative SYM group2-line simrik 대신 single-line simrik을 선택하면 FX 모양이 바뀌는지 확인.
Creative positionup icon으로 5 fan/2 fan 등 fan style이 바뀌는지 확인.

Override

Override section은 기본적으로 functional하지 않으며, solo spot/highlight 목적에 맞게 별도 setup해야 합니다.

순서Copilot 콘솔 작업감독 확인/판단
1Preset area의 아래쪽 Global presets에서 10개 override slot 확인.빈 slot/기존 label 확인.
2solo fixture 선택. 예: front truss spot 1103. dimmer 100%, white, position/zoom 조정.조준 결과와 연출 의도는 감독이 판단.
3저장 전 Stop IFX, Stop PFX preset을 눌러 running FX suppression을 포함.표준 solo spot은 켬 추천. 특수 연출은 사용자 선택.
4Store → override all preset slot에 Override.덮어쓰기 확인.
5showfile menu → regen override icon 실행.sequence 생성 확인.
6show view에서 override look 확인. 기본값은 move in black active.MIB on은 clean transition, off는 움직임을 보여주는 연출.
