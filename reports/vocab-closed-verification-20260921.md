워크시트 선택지를 문서 §1.1의 닫힌 어휘로 고정: 구간 9(Intro·Verse·Pre-Chorus·Chorus·Post-Chorus·Bridge·Rap/Solo/Dance Break·Final Chorus·Outro) · 트리거 8 · 원샷 7. 그 밖의 이름은 스크립트가 거부(`VocabError`). Rain 전체 표 + 8곡. 프로토타입 값, 실기 미접속.

## 결과

- **8곡 전부 문서 어휘만으로 큐시트가 나온다.** 내 말투("빌드업·후반·눈 리셋·히트·Finale")는 표에서 사라졌다.
- 구간 어휘 사용 5~7/9. 안 나온 것: **Post-Chorus·Rap/Solo/Dance Break** — 판정기가 못 내고 규칙으로도 못 만든다 → 감독이 확인 카드에서 지정.
- 트리거 4/8: 보컬 시작·보컬 종료·빌드업 시작·악기 추가·드롭 직전의 정적(5토큰, 문서 8항목 중 4). 안 나온 것: **코드·조성 변화 · 핵심 가사 · 안무 대형 변화 · 중심 멤버 변경** — 오디오로 못 잡음, 워크시트 입력 전용.
- 원샷 4/7: White hit·Blinder hit·짧은 Strobe·Dimmer bump. 안 나온 것: **Kick·Snare·Cymbal accent**(박자 감지 결과 `onsets_ms` 미소비) · **Color bump** · **Position snap**(포지션 프리셋 필요).
- 판정기 이름 → 문서 어휘 재매핑 곡당 1~2건(마지막 Chorus → Final Chorus, Finale → Outro), 규칙이 끼워 넣은 Pre-Chorus 곡당 1~3개. 이것들은 **"감독 확인" 표시**가 붙어 나온다(곡당 1~6건).
- 후렴 정체성은 1.0(8곡 중 후렴≥2인 7곡). Final Chorus가 별도 구간이 되면서 "마지막 후렴 흰색"이 정체성 계산에서 빠진 결과 — 어휘가 맞으니 규칙 예외(후렴 3개 미만)도 필요 없어졌다.

## 어휘가 못 채우는 자리 — 누가 채우나

| 어휘 | 자동 불가 이유 | 채우는 곳 |
|---|---|---|
| Post-Chorus · Rap/Solo/Dance Break | 판정기 5종에 없음 | 확인 카드에서 감독 지정 |
| Pre-Chorus | 판정기가 못 냄. 규칙이 후렴 앞 4마디로 끼워 넣음 | "감독 확인" 표시 → 감독이 위치 조정 |
| 코드·조성 변화 · 핵심 가사 · 안무 대형 · 중심 멤버 | 오디오 분석 범위 밖 | 워크시트 트리거 칸(감독 입력 전용) |
| Kick·Snare·Cymbal accent | `onsets_ms`를 아무도 안 씀 | 판정기 작업(t428 계열) 후 |
| Position snap | 포지션 프리셋 필요 | 리그 프리셋 후 |
| Color bump | 컬러 스크립트 규칙에 "순간 색" 항목 추가 | C1 확장 |

## 스펙에 넣을 것

1. 워크시트 3칸의 선택지를 문서 어휘로 닫는다(구간 9 + 회차 번호 칸, 트리거 8, 원샷 7). 자유 문구는 메모 칸.
2. 판정기 5종 → 문서 9종 재매핑 표를 코드에 두고, 재매핑·규칙 삽입 큐엔 "감독 확인" 표시를 화면에 낸다.
3. 자동으로 못 채우는 6종은 선택지에는 있되 기본값 없음(감독 입력 전용).
4. 큐시트 화면 열: 구간 · 회차 · 트리거 · 출처(판정기/규칙/감독). "층" 열은 없앤다.
