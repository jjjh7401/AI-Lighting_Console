# grandMA3 onPC 코파일럿 — 소개 자료 (외부 공유용)

원본: `docs/user-guide.html` (감독 워크플로우 9단계). 통신 프로토콜·내부 플러그인 등 개발 항목은 범위 제외.

## 한 줄 정의
grandMA3 onPC 위에 얹는 한국어 AI 보조 도구. 콘솔을 대체하지 않고 프로그래밍을 돕는다.

## 역할 분담
| 주체 | 맡는 일 |
|---|---|
| 조명감독 | 연출 의도 결정, 초안 채택 판단, 위험 명령 승인 |
| AI 코파일럿 | 말→명령 변환, 데이터 정리, 초안 제안, 서류 작성, 결과 검증 보고 |
| grandMA3 onPC | 실제 조명 제어, 쇼파일 보관 |
| 오퍼레이터·크루 | 현장 조작, 결과 육안 확인 |

흐름: 한국어 요청 → 코파일럿(변환 + 안전 확인 + 승인 요청) → 승인된 명령만 콘솔 → 상태 회신 → 결과 보고

## 화면 구성
상단 헤더(연결 상태·라이브 잠금·런북 모드·페이퍼워크·설정) / 콘솔 대시보드(그룹·시퀀스·프리셋·매크로 타일, 클릭=Go/Off) / 큐 모니터(익스큐터별 현재 큐·실행 이력) / 채팅 컬럼 / 런북 모드 / 페이퍼워크

## 핵심 기능 (단계별)

### 1. 패치 준비
- 설계 도면 ↔ 콘솔 실제 패치 대조 → 불일치 항목 보고
- 배치 도면 이미지 판독 → 배치 정보 추출
- 패치 CSV → 등록 계획 → 미리보기 → 사람 확인 후 실제 등록
- 장비 이름 → 픽스처 타입 매칭 / 빈 DMX 주소 구간 탐색·배정안
- 주소 중복·공백 판정, 패치시트 출력, 등록 후 콘솔 재판독 대조
- 한계: 되돌리기 없음. 채널폭 판독 경로 없어 충돌은 "확정" 불가("겹침 없음"만 증명 가능). 도면 경로는 계획만 생성, 실행은 사람.

### 2. 리그 셋업·조준
- 장비 3D 좌표 판독
- 문장 기반 조준 → 팬·틸트 계산 (좌표 지정 / "부채살로 펼쳐" 등 형태 지시 가능)
- 조준 발화 조건: 조준 동사(바라보다·비추다·향하다·조준·겨냥) + 조준점(좌표 3값 또는 중앙 계열 어휘) 둘 다 필요. 하나라도 빠지면 되묻는다.
- 일괄 배치: 격자·일렬·원형·반원·다각형, 높이 일괄 조정. 쓰기 전 백업 + 완료 후 재판독 검증
- 한계: 빔 낙하 지점 판정 불가(육안 확인). 포커싱 차트 출력 없음.

### 3. 그룹·프리셋
- 리그 전체 요약(패치·그룹·프리셋·시퀀스·매크로)
- 좌표 기반 배치 구조 판정 6종: 앞뒤 열 / 좌우 분할 / 동심원 / 층 / 격자 / 좌우 짝
- 판정 구조대로 그룹 생성, 프리셋 목록·매직시트(축약형) 출력
- 한계: 그룹 멤버 판독 불가 → 빈 슬롯 확신 불가, 기존 그룹 비교 불가, 매직시트는 멤버 목록 없는 축약형. 덮어쓰기 복원 경로 없음.

### 4. 룩·이펙트 라이브러리
- 룩 32개 (발라드 7 / 록 8 / EDM 9 / 워십 8)
- 이펙트 19개 (무브먼트 11 / 디머 5 / 컬러 3)
- 완성 장면 5개, 장르 팔레트 4개 장르 일괄 생성
- 문장 검색 → 실제 리그 역할에 매핑해 프리셋 저장 / 이펙트 적용·조합 / 장면을 시퀀스+큐로 한 번에 얹기
- 이펙트 요청 시 대상 그룹 + 저장 위치 둘 다 필요
- 한계: 룩·이펙트를 나눠 요청하면 값 빠진 큐가 조용히 저장됨 → 한 번의 요청으로. 미적 판단 없음. 사용자 룩/장르 추가 경로 없음. 참고 이미지 색감 추출 없음.

### 5. 큐리스트
- 구간 이름 + 시작 시각 입력 → 구간별 룩 배정 → 곡 1개 = 시퀀스 1개
- 큐시트 출력(큐 번호·이름·트리거 종류), 익스큐터 배선 계획서
- 한계: 페이드 시간 미포함(읽는 경로 미확인 → 지어내지 않고 비움). 음원 자동 구간 분할 없음. 타임코드 오브젝트 생성 불가.

### 6. 리허설·본공연
- 콘솔 상태 조회 / 문장으로 수정 → 커맨드 실행
- 큐 모니터: 익스큐터별 현재 큐·실행 이력 실시간. 앱 명령=확인 표시, 콘솔 직접 조작=회색(정상)
- 공연 전 자동 점검: 통신 상태 / 시퀀스·익스큐터 존재 / 프리셋 라이브러리 / 알려진 함정
- 쇼 컨트롤 패널: 타일 클릭 Go, 재클릭 Off. 타일 순서·번호 고정
- 런북 모드(곡명+큰 버튼만), 라이브 잠금(실행 전면 차단, 상태 조회는 유지)
- 한계: 큐 내용 판독 불가 → 다음 Go 결과 미리보기 불가. 되돌리기 없음. 장비 반응 자동 감지 불가. 단일 onPC 기준.

### 7. 서류·인수인계 (5종)
패치시트 / 큐시트 / 프리셋 목록 / 매직시트(축약형) / 인수인계 패키지(묶음 + 불완전성 요약 첫 화면)
- 모든 서류에 불완전성 배지: 목록 잘림 / 파고들 예산 소진 / 내용 열지 못함
- 원칙: 읽지 못한 것은 읽지 못했다고 적는다
- 한계: 매직시트 멤버 목록 없음, 큐시트 페이드 없음, 쇼파일 복원은 콘솔에서 직접

## 안전 설계
모든 명령: 문법 검증 → 위험 분류 → 사람 승인 (우회 경로 없음)

| 장치 | 동작 |
|---|---|
| 라이브 잠금 | 실행 전면 차단, 제안만 표시 |
| 쇼파일 자동 백업 | 세션 시작 + 10분 간격 + 위험 명령 직전 |
| 감사 로그 | 실행·승인·거부 기록, 90일 보관 |
| 자가 수정 제한 | 재시도 최대 3회 |
| 스트로브 경고 | 광과민성 발작 위험 패턴 감지·경고 |
| 콘솔 오프라인 차단 | 통신 불가 시 모든 실행 차단 |
| 묶음 전체 취소 | 묶음 중 하나라도 거부되면 전체 취소 |

## 역할의 경계
미적 최종 판단 / 공연 중 자동 조작(설계상 의도적 제외) / 콘솔 대체 / 그룹·큐 내용 판독 / 되돌리기 / 도면 작성 — 모두 앱의 범위 밖.

## FAQ (요지)
- 인터넷 없는 공연장: AI 변환은 인터넷 필요, 저장된 큐·매크로 실행은 불필요
- 쇼파일 손상: 위험 명령 사람 승인 + 자동 백업, 단 앱 복원 경로 없음
- 콘솔 문법 불필요, 결과 확인은 콘솔 화면에서
- 타임코드: 구간 마커·시간 기반 큐리스트까지. 타임코드 오브젝트·레코딩은 콘솔에서
- 볼런티어 위임: 런북 모드 + 라이브 잠금 동시 사용
- "읽지 못했다" 표시는 오류가 아닌 설계된 표시
