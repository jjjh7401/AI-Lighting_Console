# grandMA3 AI 코파일럿 — 전체 구조

> 기준: `origin/main 7ce0652` · 2026-09-08 · 읽기 전용 실측

## 한 문단

한국어로 조명 지시를 하면 grandMA3 콘솔 명령으로 옮겨서 OSC 로 실행한다. 되돌릴 수 없는
동작은 3단 안전 게이트가 막는다. 추적 파일 2,166개 중 제품 코드는 `server/` 597개(25개 패키지,
9.2만 줄), 테스트는 317파일 15.8만 줄이다.

## 명령이 지나가는 길

사용자 문장 → 채팅 UI → 세션 → 오케스트레이터(도구 34종) → **안전 게이트** → OSC 브리지 →
콘솔 응답기(Lua 1.6.5) → 콘솔. 되읽기는 역방향으로 같은 길을 돌아온다.

게이트가 유일한 관문이다 — `screen()` 하나뿐이고, 두 번째 진입점을 만드는 것은 구조적으로
게이트 우회라고 코드가 못박는다(`@MX:ANCHOR`, fan_in ≥ 3).

## 안전 게이트 — 3단

| 단계 | 하는 일 |
|---|---|
| 건강 검사 | 콘솔이 살아 있나 · 응답기 버전이 맞나 · 백업이 됐나 |
| 문법 | 명령이 MA3 문법으로 파싱되나 |
| 분류 | 각 명령이 안전한가 · 보류인가 |

이후 라이브 잠금 재확인 → 승인 카드 → 위험 경로 백업 → 실행 → 감사 기록.

게이트 판정: `cleared` · `held` · `rejected` · `blocked`(+ 사유별 5종: 콘솔 오프라인 ·
문법 · 응답기 성능저하 · 버전 불일치 · 버전 미상 · 백업 실패).

## 이 채널이 못 하는 것 — 셋

1. **값을 못 읽는다.** 슬롯 점유와 이름까지다. 이름이 맞다고 색이 맞는 것이 아니다.
2. **`0` 은 부재의 증거가 아니다.** 내용이 있는 Group 이 `COUNT 0` 을 답한 사례가 있다.
3. **자식 목록이 잘린다.** `childCount` 대조 없이 세면 21을 13으로 센다.
