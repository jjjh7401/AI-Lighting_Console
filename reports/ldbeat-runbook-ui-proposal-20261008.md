# 런북 모드 박자 배치 — UI 제안 (md 요약판)

- 2026-10-08 · SPEC-LDBEAT-001 · 사람용 본문 `reports/ldbeat-runbook-ui-proposal-20261008.html`(눌러 보는 시안, 데이터 0~25마디)
- 감독 요청: 직전 시안은 한 번에 다 보여 주려다 너무 길다 — 곡 전체 흐름 + 마디별 효과 확인 + 직관적 수정을 한 UI 로. 좌우 스크롤 방식도 나쁘지 않았음.

## 구조 (한 화면 높이 고정, 위→아래)
1. 상단 바: 곡·버전·BPM · ◀ 마디 ▶(←→ 키) · ▶ 이 마디 콘솔에서 보기 · ■ 끄기 · ⇪ 콘솔에 반영(대기 수) · 프리셋 서랍
2. 곡 전체 지도: 82마디 한 줄 — 구간 띠 · 에너지선 · 강조 ★(18·46·63·67) · 지금 보는 범위 창 · 재생 위치. 클릭하면 점프. 확대: 곡 전체 / 16마디 / 8마디
3. 장비 그룹 줄 타임라인(좌우 스크롤): 줄 = 콘솔 그룹 = 시퀀스, 큐 하나 = 막대 하나(경계 = 바뀌는 곳). 막대에 효과 이름·위치·밝기, 색 = 색 프리셋, 아래 흰 선 = 밝기, 효과 모양 아이콘(펄스/스윕/웨이브). 고친 막대 초록, 같은 프리셋 노랑, AI 제안 점선
4. 상세 창(고정 높이 3칸): 무대 개념도 · 「이 마디 한눈에」 6역할 짧은 표(밝기·위치·색·효과 칩 + 바뀐 것) · 고른 큐 편집(밝기 값/디머 프리셋/디머 효과, 위치, 색, 움직임 + 콘솔 명령 접기)
5. 명령창: 문장 「(마디) (역할) (밝기|위치|색|효과)를 (프리셋 이름)으로」 바로 적용 / AI 제안(점선 막대 → 수락·거절)
6. 프리셋 서랍: 풀별(디머 1 · 위치 2 · 색 4) 목록, 쓰는 큐 수, 누르면 쓰는 막대 강조, 프리셋 고치기

## 이전 시안과 비교
| | 격자(첫 시안) | 표+목록(직전) | 제안 |

## 유지되는 규칙
콘솔 이름 영문(`4.24 LA Pink`) 우선 · 미확인 효과 ⚠ · 미리보기 = Goto 재생만 · 반영 = 승인 1회 + 승인=송신 대조 · 실기 미확인 항목은 직전 시안 §6 과 같음.

## 타임라인 줄은 누가 정하나 (감독 질문 2026-10-08 「역할은 누가 어떻게 정하나, 장비별이 아니라 역할인가」)
| 층 | 무엇 | 누가 |
|---|---|---|
| ① 장비 그룹 = 줄 | 콘솔 그룹(FOH G3 · WASH-ALL G10 · BACK G4 · SIDE-ALL G7 · MOVER-U G11 · MOVER-D G12 · BLIND G14 · STROBE) | 쇼파일 — 앱은 읽기만, 쓸 줄은 감독이 고름 |
| ② 층 역할 = 줄 이름표 | 앱 어휘 key·back·side·wash·mover·effect·audience (`server/design/rig.py` RIG_LAYER_ROLES) | 앱이 그룹 이름 정확 일치·접두어로 제안 → 감독 확인(기존 `_confirm_song_layer_mapping`), 감독 선언이 우선 |
| ③ 효과 = 막대 내용 | 펄스·체이스·스윕·웨이브 | 규칙서 기본값 → 감독 수정 |
- 정정: 이전 시안 SCENE·BACK PULSE·SIDE CHASE·ACCENT 는 장비와 효과를 섞은 임시 이름이었음(SCENE = 워시+앞빛 두 그룹).
- 겹치는 그룹(MOVER-ALL 과 MOVER-U 등)은 동시에 줄로 못 씀 — 같은 장비를 두 시퀀스가 잡으면 LTP 로 섞임.

## 큐 운영 — 이음매 (감독 질문 2026-10-08 「큐 길이·전환 타이밍·MIB 는 큐와 큐 사이라 표로 어렵다」)
- 큐 사이 운영은 막대가 만나는 **이음매**에 그림. 저장은 MA3 처럼 **들어오는 큐**에(페이드·딜레이는 다음 큐 속성).
- 큐 길이 = 막대 길이(이음매 끌기 = 다음 트리거 이동, 박 단위) [잰 것: TC 이벤트 시각 t520]
- 트리거 = 이음매 위치, 마디·박 선택 [잰 것: 소수 시각 이벤트 t520]
- 페이드 = 다음 막대 왼쪽 색 번짐 + ◢ [잰 것: CueFade, CUETIME 5초 페이드]
- 딜레이·속성별(위치만 늦게) [미확인: emit.py 축별 timing 거부]
- MIB = 이음매 M — 앞 큐 꺼짐 + 위치 바뀜이면 앱이 Cue n.5 위치 전용 큐 삽입 [잰 것: server/spatial/mib.py, CUETIME M2 4,731px→0px]; 켜진 채 위치 바뀜은 「MIB 불가」 알림
- 트래킹 Track/Cue Only/Block/Release [어휘 있음 REQ-LDDESIGN-053, 콘솔 송신 없음]
- 경고 ! = 켜진 채 위치 끊어 바뀜, 구간 경계 밖 색 끊김 [제안: 규칙서 §2.3 규칙 2 검사]
- 장면 전환 줄: 3줄 이상 동시에 바뀌는 마디에 알약 → 그 순간 전체 표 + 「모두 끊기/모두 1박 페이드」

## 시간 표기 (감독 2026-10-08 「페이드 4박이 무슨 뜻이냐, 초도 아니고」)
- 화면은 초를 먼저, 박·마디는 괄호: 「2.14초 (1마디)」 「1.07초 (2박)」. 콘솔 저장은 초(CueFade). 박 입력도 허용(LOVE ATTACK 1박 = 0.534초, 4박 = 1마디).

## 중복 제거 + 접는 폴더 (감독 2026-10-08 「표와 편집 칸이 중복」「장비·역할이 많아지면?」) — 시안에 적용됨
- 「이 마디 한눈에」 표 칸(밝기·위치·색·움직임)을 눌러 그 자리에서 고침. 오른쪽 칸은 표에 없는 것만(장비·Seq/Cue·큐 길이·들어올 때 전환·쓰는 프리셋·콘솔 명령).
- 줄 3단: ① 층 역할 폴더(접으면 요약 한 줄 — n/m줄 켜짐, 바뀌는 경계) ② 콘솔 그룹(부모·자식 그룹 그대로: MOVER-ALL/U/D 등, rig.py 접두어 매칭) ③ 자식 줄은 감독이 「이 구간 L·R 따로」 할 때만 생김(나머지 「따름」), 「다시 합치기」로 제거.
- 시안 초기 상태: 효과 폴더 접힘, 옆빛 11~13마디 SIDE-L/R 갈라짐(R 만 핑크).
- 검증: headless Chrome 상호작용 시험 — 갈라짐 자식 줄 2 · 접힌 요약 막대 생성 · 표 칸 인라인 편집으로 MOVER-D 색 4.25 반영 · 전환 편집 열림 · 스크립트 오류 0.
- 위험: 줄 = 시퀀스 = TC 트랙 — 줄이 많으면 트랙 증가(실기 2개까지만 확인). 폴더를 시퀀스 하나로 합치는 방법은 M1 확인 항목.

## 상세 칸 제거 (감독 2026-10-08 「이것도 반복 아니냐, 상세가 필요하냐」) — 시안에 적용됨
- 상시 오른쪽 상세 칸 삭제: 「쓰는 프리셋」은 표 칩과 중복, 큐 길이는 막대 길이, 들어올 때 전환은 표 전환 칸과 중복이었음.
- 상세(장비 번호·Seq/Cue·마디 범위·길이·타임코드 시각·콘솔 명령)는 표의 줄 이름 ▸ 를 누르면 그 줄 아래 한 줄로만 펼침. 프리셋 사용 곳 수는 칩 툴팁.
- 오른쪽 칸은 전환 편집(이음매·장면 전환 알약)이나 AI 제안을 열 때만 나타남. 평소엔 무대 그림 + 표 두 칸.
- 검증: headless 상호작용 — 펼친 줄 1 · 평소 2칸 · 전환 열면 3칸/닫으면 2칸 · L·R 가르기/합치기 · AI 제안 열림/수락 후 닫힘 · 오류 0.

## 무대 보기 3가지 (감독 2026-10-08 「장비가 많아지면 개념도로 가능한가, 다른 방법은」) — 시안에 적용됨
- 기본 **상태판**: 장비 한 대 = 작은 칸, 줄(그룹)별로 늘어놓음. 색 = 색 프리셋, 진하기 = 밝기, 깜박임 = 디머 효과, ↔↕ = 움직임. 폴더를 접으면 상태판도 한 줄 — 수백 대여도 크기 일정. 실제 위치는 안 보여 줌.
- **평면도**: 지금 시안은 개념도. 앱에서는 패치 좌표(Posx·Posy, `get_spatial_context`·`server/spatial/pointing.py` 가 이미 읽음)로 실제 위치에 점 — 손그림이 아니라 리그가 커져도 맞음.
- **3D 캡처**: 「이 마디 콘솔에서 보기」 뒤 onPC 3D 창 스크린샷을 표시(실제 결과). 근거: `screencapture -l <windowid>` 를 조준 검증·CUETIME 픽셀 비교에서 이미 사용 [잰 것]. 실물 콘솔에서는 같은 방법 불가 — 비주얼라이저/캡처 장비 필요 [미확인]. 장면 전환마다 찍어 곡 전체 지도 아래 썸네일 띠로.

## 무대 보기 다시 (감독 2026-10-08 「상태판은 의미 없고 3D 캡처는 실현 안 될 것」) — 시안에 적용됨
- 상태판·평면도·3D 캡처 탭 삭제. 앱 안에 무대를 그리지 않는다 — **콘솔 화면(onPC 3D 또는 실제 무대)이 무대 보기**.
- **콘솔 따라 보기**: 켜면(재생 명령 Goto·Off 만 허용하는 승인 1회) 앱에서 마디를 옮길 때마다 바뀐 줄만 `Goto Cue k Sequence S` 로 콘솔도 그 마디로 감. 장비 수와 무관. [잰 것: Goto Cue 1 한 줄 · Off] [미확인: 2번 이후 큐 · 여러 줄 동시]
- **장면 문장**: 그림 대신 「이 마디에서 바뀌는 것」(무엇이 · 끊어서/번짐) + 「지금 켜진 것」(어디 · 몇 대 · 색 · 밝기/깜박 · 높이 · 움직임) + 「꺼짐」. 데이터에서 자동 생성, 리그가 커져도 폴더 단위로 묶어 읽힘.
- 실제 좌표 평면도는 필요해지면 나중 후보(패치 Posx·Posy 를 앱이 이미 읽음).

## 막대 → 오른쪽 큐 편집 (감독 2026-10-08 「막대를 누르면 우측에 그 장비 상세가 나오고 거기서 수정」) — 시안에 적용됨
- 타임라인 막대(큐) 클릭 → 오른쪽 칸에 그 장비 줄의 큐 상세 + 편집: 장비·Seq/Cue·마디 범위·길이·타임코드 / 밝기(값·디머 프리셋·디머 효과)·위치·색·움직임 / 들어올 때 전환(초 + 박, MIB·경고, 「전환 자세히」) / L·R 가르기(옆빛) / 콘솔 명령.
- 고치는 곳은 오른쪽 한 군데. 가운데 「이 마디 한눈에」 표는 훑어보기 전용 — 칸·줄을 누르면 오른쪽 편집이 그 항목에 초점을 두고 열림.
- 「전환 자세히」를 닫으면 큐 편집으로 돌아오고, ✕ 로 닫으면 두 칸 화면.
- 검증: headless — 첫 화면 BACK 'Back Hold' 편집 열림 · MOVER-D 막대 클릭 → 편집 · 색 4.24 반영 · 전환 자세히 ↔ 복귀 · 닫기 · 표 칸 클릭으로 WASH-ALL 편집 · 오류 0.

## 2D 무대 그림 복귀 (감독 2026-10-08 「문장 설명·콘솔 따라 보기는 직관적이지 않다, 아까 2D 가 낫다」) — 시안에 적용됨
- 장면 문장·콘솔 따라 보기 삭제(위 「무대 보기 다시」 절은 철회). 무대 칸 = 2D 그림.
- 추가: 고른 줄의 장비에 노란 점선 테두리 · 그룹 이름표(FOH·WASH·BACK·SIDE-L/R·U·D·BLIND) · 그림의 장비 영역을 누르면 그 줄 큐 편집이 오른쪽에 열림 · 옆빛 L·R 갈라진 구간은 좌우 색이 따로.
- 앱에서는 손그림 대신 패치 좌표(Posx·Posy)로 실제 위치에 그림 — 큰 리그 대응은 이 좌표 그림 + 폴더 접기.

## 편집 칸 위치 (감독 2026-10-08 「타임라인 오른쪽에 길게 — 밝기·위치·색·들어올 때」) — 시안에 적용됨
- 큐 편집은 타임라인 바로 오른쪽 세로 칸(폭 310px, 높이 = 타임라인 높이)에 위→아래로: 머리(줄·Cue·장비·마디·초·타임코드) → 밝기 → 위치 → 색 → 움직임 → 들어올 때(초 + 박, MIB·경고, 전환 자세히) → 옆빛 L·R → 콘솔 명령.
- 같은 칸에 전환 편집·장면 전환·AI 제안도 열림. 아무것도 안 골랐을 때는 안내문.
- 아래 칸은 2D 무대 그림 + 「이 마디 한눈에」(훑어보기) 두 칸.
- 검증: headless — 첫 화면 BACK 편집 · MOVER-D 막대 클릭 → 오른쪽 세로 칸 편집 · 색 반영 · 전환 자세히 · 닫기 → 안내문 · AI 제안 · 칸 높이 = 타임라인 높이 · 오류 0.

## 전환·콘솔 명령 버튼 (감독 2026-10-08) — 시안에 적용됨
- 「전환」 버튼: 편집 칸 오른쪽 위(✕ 옆). 누르면 전환 상자(트리거 박 · 딜레이 초+박 · 위치만 따로 · MIB · 트래킹 · 이유)가 「들어올 때」 아래에 열리고, 다시 누르면 닫힘. 켜지면 노란 버튼. 곡 첫 큐는 비활성.
- 「콘솔 명령」 버튼: 편집 칸 맨 아래. 누르면 그 큐 명령 + 전환(CueFade·TC 이벤트) 표시, 다시 누르면 닫힘. 켜지면 노란 버튼.
