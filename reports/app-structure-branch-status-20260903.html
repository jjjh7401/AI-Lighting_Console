1. 닫아도 되는 상태인가?

2. 전체 앱 구조도

앱은 React UI, Python backend, grandMA3 Lua responder, Tauri shell 네 부분으로 나뉩니다. 콘솔을 바꾸는 모든 명령은 backend의 SafetyGate를 지나야 합니다.

3. 런타임 데이터 흐름

사용자 지시 → 콘솔 실행

  1. UI가 protocol v1 JSON frame을 ws://host:8765/ws로 전송.
  2. server/web/app.py가 handshake, busy guard, approval/question events를 관리.
  3. ChatSession이 첨부, Vectorworks upload, timeline, progress stream을 한 세션으로 묶음.
  4. Orchestrator가 provider-neutral tool loop 실행.
  5. SafetyGate가 문법, 위험도, 승인, 백업, live lock을 검사.
  6. server/bridge/protocol.py가 responder plugin command를 만들고 결과를 decode.

보호 장치

  • 단일 chokepoint: console-bound command는 SafetyGate 통과.
  • deny by default: 위험 명령, plugin deploy, review disconnect는 거부 쪽으로 닫힘.
  • Korean-only UI errors: raw SDK error는 사용자 프레임에 직접 노출하지 않음.
  • Origin/token handshake: local cross-site WebSocket hijacking 방어.
