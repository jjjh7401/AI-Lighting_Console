콘솔이 값을 주는가

채널폭 · 페이드 시간 · 큐 내용 · 그룹 멤버십 — 네 항목이 전부 “콘솔이 그 값을 돌려주는가”에 걸려 있습니다. 읽기 프로브 한 번이면 넷이 같이 판가름납니다. 재보지 않고 착수하면 다 만든 뒤에 전제가 거짓으로 드러납니다.

단계별 16건

각 항목은 세 가지를 갖춥니다 — 어디서 막히는가, 무엇을 관측했는가, 다음에 무엇을 정해야 하는가. “좋아지면 좋겠다” 수준의 문장은 항목으로 넣지 않았습니다.

1도면 수령

도면과 현장이 어긋났을 때 어느 쪽이 맞는지 앱이 판정하지 못한다

관측대조 기능은 등록돼 있으나 판정 기준을 담은 경로가 없다
정할 것어긋남을 유형별로 분류할 것인가, 감독 판정만 돕는 표로 남길 것인가
2패치

장비 채널폭을 직접 읽지 못해 주소 충돌을 확정 판정할 수 없다

관측겹침 판정 기능은 등록됨. 개정 전 가이드도 “충돌 가능은 상계”라 적었고, 이번 실측에서도 판독 경로가 확인되지 않았다
정할 것채널폭을 읽는 경로가 있는지 비파괴 프로브로 먼저 판정하고, 없으면 상계 판정을 문서 계약으로 고정
2패치

서버가 패치를 콘솔에 직접 써넣지 못해 사람이 플러그인을 실행해야 한다

관측실행 경로가 이 빌드에서 동작하지 않는다는 것이 기능 계약에 명시돼 있고 대응 테스트가 존재한다
정할 것이 제약을 영구 계약으로 굳힐 것인가, 다른 실행 경로를 재측정할 것인가
3셋업·포커싱

조준 기능이 기능 목록에 나타나지 않아 감독이 존재를 알 수 없다

관측조준은 자연어로 도달하지만 등록 기능 33종에는 없다
정할 것조준을 정식 기능으로 노출할 것인가, 목록에 비기능 항목을 추가할 것인가, 문서로만 안내할 것인가
3셋업·포커싱

포커싱 결과를 정리한 차트가 없다

관측좌표 판독은 되지만 팬·틸트 현재값을 문서로 뽑는 기능이 등록 목록에 없다
정할 것포커스 값 판독 경로를 먼저 측정하고, 가능하면 차트를 서류 종류에 추가
4그룹·프리셋

그룹 안에 어떤 장비가 들어 있는지 읽지 못해 매직시트가 축약형에 머문다

관측응답기가 그룹 내용을 주지 않아 총계 승격을 막는 처리가 코드에 들어 있다. 매직시트 기능 자체는 등록됨
정할 것멤버십을 우회 판독할 경로가 있는지 판정하고, 없으면 축약형을 최종 형태로 확정
4그룹·프리셋

덮어쓴 그룹과 프리셋을 되돌릴 수 없다

관측백업은 있으나 복원 경로가 없다. 삭제 계열은 승인 필수로 묶여 있다
정할 것스냅샷 로드 경로를 측정하고, 가능하면 승인 게이트를 통과하는 복원 명령을 설계
5룩·이펙트

사용자가 직접 룩이나 장르를 정의해 라이브러리에 넣을 수 없다

관측내장 장르는 4개, 룩 32개가 파일로 고정돼 있다
정할 것사용자 정의를 파일 편집으로 열 것인가, 화면에서 저장하는 학습 기능으로 열 것인가
5룩·이펙트

참고 이미지에서 색감을 뽑아 룩으로 옮기는 경로가 없다

관측이미지 판독 기능은 배치 도면용으로 등록돼 있고 룩 매칭과는 연결돼 있지 않다
정할 것이미지 판독의 출력을 룩 검색 입력으로 이을 수 있는지, 별도 경로가 필요한지
6큐리스트

큐시트에 페이드 시간이 들어가지 않는다

관측큐시트 기능은 등록됨. 페이드 값 판독 경로가 확인되지 않아 비워 둔 상태다
정할 것페이드 속성을 읽는 경로를 측정하고, 불가하면 비움을 명시적 계약으로 고정
6큐리스트

음원에서 구간을 자동 분할하지 못해 사람이 구간을 적어야 한다

관측큐리스트 기능은 구간 정보를 입력으로 받는다. 오디오 입력 경로가 없다
정할 것오디오 의존성과 업로드 경로를 함께 열 것인지, 구간 입력을 더 쉽게 만드는 쪽으로 갈 것인지
7리허설

큐 내용을 읽지 못해 다음 Go가 무엇을 바꾸는지 미리 보여 줄 수 없다

관측상태 조회는 되지만 큐 내부 값 판독 경로가 없다. 리허설에서 가장 아쉬운 지점
정할 것큐 내용 판독 경로를 측정하고, 가능하면 런북과 큐 모니터에 변화 설명을 붙일 것
7리허설

수정을 되돌리는 경로가 없어 손으로 다시 바꿔야 한다

관측실행 경로는 있으나 취소 개념이 없다
정할 것세션 단위 되돌리기를 기록 기반으로 재구성할 것인가, 콘솔 스냅샷에 의존할 것인가
8본공연

장비가 실제로 반응했는지 자동으로 감지하지 못한다

관측콘솔이 되돌아오는 신호를 주지 않아 원리적으로 불가하다. 대체 수단인 응답 확인 매크로는 이미 있다
정할 것원리적 불가를 계약으로 고정하고, 사람 확인 절차를 문서화된 체크리스트로 승격할 것인지
8본공연

여러 콘솔이 물린 네트워크 환경을 다루지 못한다

관측단일 onPC 기준으로 설계돼 있다. 공연 전 점검도 단일 대상이다
정할 것다중 콘솔을 범위에 넣을 것인지, 명시적 비범위로 문서에 고정할 것인지

인수인계 패키지가 담지 못하는 항목이 세 가지 남는다

관측그룹 멤버십과 페이드 시간이 비고, 복원 경로가 없다
