Round-trip · 한 번의 요청이 흐르는 길

"무버 9대를 파랗게, 천천히 원을 그리게"

한 문장을 넣었을 때 시스템 안에서 실제로 일어나는 일. 각 단계는 색으로 담당 주역을 표시합니다.

사용자
평소 말로 요청합니다. "무버 9대를 파랗게, 천천히 원을 그리게 해줘"
앱
룰북(사용법 지식)을 시스템 프롬프트로 붙여 Gemini에게 요청을 전달합니다. 룰북은 MA3 문법·연출 패턴을 담은 마크다운 모음입니다.
LLM · Gemini
필요한 도구를 호출합니다. 먼저 get_rig_context로 실제 리그를 확인하고, 색·움직임·속도를 정해 run_commands로 커맨드를 만듭니다.
앱 · 안전 게이트
커맨드 묶음을 통째로 검사합니다(all-or-nothing). 위험하거나 콘솔이 응답 없으면 실행을 막고 LLM에 되돌려 자가수정하게 합니다.
OSC → 콘솔
검증된 커맨드를 단일 창구(OSC/UDP)로 보냅니다. 콘솔 속 CopilotResponder가 Cmd()로 실제 실행 — 픽스처가 파랗게, 페이저가 원을 그립니다.
결과 회신
콘솔이 퍼센트-인코딩 JSON으로 결과를 회신하고, Gemini가 성공을 확인한 뒤 사용자에게 무엇을 만들었는지 우리말로 설명합니다.

The LLM's hands · 네 가지 도구

LLM이 콘솔을 만지는 네 개의 손

Gemini는 자유롭게 아무 명령이나 실행하지 않습니다. 앱이 열어준 딱 네 개의 도구만 호출할 수 있고, 모든 실행은 이 도구를 통해 안전 계층을 거칩니다.

Why the app exists · 안전 계층

앱의 진짜 가치 — 안전하게 콘솔을 지킨다

LLM은 실수할 수 있고, 라이브 무대에서 잘못된 명령은 위험합니다. 앱은 LLM과 콘솔 사이에서 여러 겹의 안전장치로 실제 실행을 통제합니다.

안전 게이트

Gate

커맨드 묶음을 실행 전 통째로 검사합니다. 하나라도 막히면 전부 중단(all-or-nothing)하고 이유를 LLM에 돌려줍니다.

배포 파이프라인

Deploy

Lua 플러그인은 컴파일 체크 → 파괴적 명령 스캔 → 사람 승인을 통과해야만 콘솔에 올라갑니다.

헬스 모니터

Health

콘솔이 오프라인이거나 응답이 없으면 새 실행을 차단합니다. 성공적인 핑으로만 복구됩니다.

세션 백업

Backup

세션 시작 시 쇼파일을 백업 시도합니다. 되돌릴 수 있는 안전망을 먼저 확보합니다.

감사 로그

Audit

보낸 명령을 1:1로 기록합니다. 무엇이 언제 콘솔에 나갔는지 추적 가능합니다.

단일 송신 창구

Chokepoint

콘솔로 나가는 OSC 통로는 오직 하나. 게이트를 우회하는 경로가 원천적으로 없습니다.

Inside the console · CopilotResponder

콘솔 속에 사는 요원

앱은 콘솔을 직접 만지지 않습니다. 콘솔 안에 심어둔 Lua 플러그인 CopilotResponder가 OSC 메시지를 받아 대신 실행하고, 결과를 퍼센트-인코딩 JSON으로 되돌려줍니다.

OSC round-trip · /copilot
# 앱 → 콘솔 (/copilot/cmd) → Plugin "CopilotResponder" "exec h-1 Go+ Executor 111" # 콘솔 → 앱 (/copilot/feedback) ← { "id":"h-1", "kind":"result", "ok":true, "result":"OK" }
ping살아있는지 확인 · 헬스 체크(pong 회신)
exec커맨드 라인 실행 · 성공/실패 결과 회신
state오브젝트 트리 스냅샷 조회
deployLua 플러그인 배포(원격 폴백; 주 경로는 file+Import)
