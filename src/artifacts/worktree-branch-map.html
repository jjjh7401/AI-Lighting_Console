3. 읽는 법 & 권고

  • 워크트리 = 같은 저장소를 다른 폴더에 하나 더 펼친 것. 폴더마다 서로 다른 브랜치를 체크아웃할 수 있고, 커밋 이력(.git)은 전부 공유합니다. 그래서 세션끼리 폴더만 다르면 안전하게 병행 작업이 됩니다.
  • Vectorworks 신규 작업은 인계 메시지대로 --worktree로 시작하면 이 목록에 새 폴더가 하나 더 추가되는 형태가 됩니다. 메인 폴더(MCP)와 충돌하지 않습니다.
  • 잔재 10개는 정리 후보입니다. 다만 스쿼시 머지 특성상 "머지됨"을 커밋 숫자만으로 단정할 수 없으니, 지우기 전에 각 폴더에 미커밋 변경이 없는지(git -C <폴더> status) 확인 후 git worktree remove <폴더>로 제거하는 것이 안전합니다. 삭제는 사용자 승인 후에만.
  • e2e-live(INTROSPECT)는 삭제 금지 — run 완료 상태이며 main 리베이스만 남은 살아있는 작업입니다.
