# rules-diet — 상시 적재 규칙 축소 도구 (카드 t613)

세션 시작 경고(instruction files 합계 > 150.0k자)를 막으려고 `.claude/rules/moai/` 의 큰 규칙 9개에서 상세 절을 `*-deferred.md` companion(원문 그대로, `paths:` 지연 로드)과 `.moai/docs/kanban-lead-protocol.md`·`.moai/docs/lane-protocol.md` § 부록으로 옮겼고, 원 파일에는 포인터와 [HARD] 한 줄만 남겼다. `moai update` 는 `.claude/rules/moai/` 를 지우고 템플릿으로 다시 까므로(파일 단위 제외 장치는 없다 — `.moai/reports/t613/apply.md`), 업데이트를 실행했다면 저장소 루트에서 `python3 .moai/tools/rules-diet/reapply.py` 를 돌려 줄인 판본(`snapshot/`, 선행 점은 `dot-claude` 처럼 저장해 규칙으로 읽히지 않게 했다)과 지워질 local-only 2개(`session-handoff-fields.md`, `worktree-integration-detail.md`)를 되입히고 합계 점검을 같이 받는다(`--dry-run` 은 다른 파일만 나열). 합계만 보려면 `check.py`(150,000자 초과 시 종료 코드 1), 조항이 하나도 안 빠졌는지는 `verify.py`(원본 커밋의 모든 줄이 줄인 파일+companion 에 있는지), 스냅샷을 다시 만들려면 `build.py`(`BASE_REF` 커밋 기준, 결정적). 규칙을 고치면 스냅샷도 같은 변경으로 갱신해야 다음 재적용에서 되돌아가지 않는다.
