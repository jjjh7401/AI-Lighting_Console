# t484 판정서 — 색 이름이 0개인 Q2 후보 9개 조사·제안 (1단계)

- 카드: t484 · 브랜치 `WT-q2-colorless` · 기준 `origin/main` = `a3364205` (t483 머지 포함)
- 범위: 조사·제안만 한다. 코드와 표준 문구는 바꾸지 않았다(표준 문구 변경은 감독 결정). 콘솔 쓰기 0.
- 증거: `uv run python .moai/reports/t484/probe_colorless_q2.py` → `probe_colorless_q2.txt`

## 요약

- Q2 후보 17개를 전수로 조사했다. 그중 **9개는 RGB로 풀리는 색 이름이 하나도 없다**(팝, 빈티지, 무드 6개, 기본).
  t483은 앞머리 수식어만 건너뛰므로 이 9개에는 효과가 없다.
- 곡 큐 경로(t441 5구간 픽스처)로 실행한 결과, 9개 모두 **5구간 중 5구간**에서
  `director color '…' is not in the standard 10-color palette — this section's look color was left unchanged`가 나왔다.
  대조군 `블루`는 실패 0이다.
  → 이 경로에서는 색 줄이 0개가 되는 것이 아니다. **감독이 고른 색 대신 룩 자체의 색이 남는다**
  (사유 문구로 확인). 웹 경로(경로 A)는 이번에 재지 않았다.
- 제안은 세 묶음이다.
  - **문구 보강만으로 바로 풀린다** — 3개(Ring In, Cross, Wall).
  - **흰색 별칭이 있어야 뜻대로 풀린다** — 4개(빈티지, Center, Home, 기본). 코드 변경과 감독 판정이 필요하다.
  - **'색 미정'으로 표시** — 2개(팝, Fan Out).

## 먼저 알아야 할 사실 — 흰색 계열은 지금 Q2 문구로 표현할 수 없다

| 입력 | `resolve_color_name` | `_palette_value_tokens` |
|---|---|---|
| `웜화이트` | None | `('웜화이트',)` |
| `쿨화이트` | None | `('쿨화이트',)` |
| `Warm White` | (100,75,40) | `('Warm', 'White')` — 공백에서 쪼개져 두 토큰 모두 안 풀린다 |
| `Cool White` | (85,95,100) | `('Cool', 'White')` — 위와 같다 |
| `화이트` | None | t409 감독 결정: 맨 흰색이 Warm White와 Cool White 중 어느 쪽인지는 감독만 정한다 |

따라서 색온도(웜/쿨 화이트)가 뜻인 후보는 표준 문구에 어떤 단어를 넣어도 지금 코드로는 흰색이 되지 않는다.
`웜화이트`→Warm White, `쿨화이트`→Cool White 별칭은 모호함이 없는 이름이다(맨 `화이트`와 다르다).
다만 색 어휘를 추가하는 일이므로 코드 변경과 감독 확인이 필요하고, 이 카드의 범위 밖이다.

지금 풀리는 이름(실측): `앰버`(100,55,5) · `블루`(5,20,100) · `시안`(0,90,100) · `레드` · `마젠타` · `퍼플`(→Lavender).

## 감독 결정이 필요한 것

1. **흰색 별칭 두 개**(`웜화이트`→Warm White, `쿨화이트`→Cool White)를 색 어휘에 넣을지 — 네 후보(빈티지, Center, Home, 기본)가 여기에 걸린다. 넣으려면 코드 카드가 필요하다.
2. **표준 문구 보강 3건**(Ring In `블루`, Cross `앰버`, Wall `블루/시안`)을 받을지.
3. **팝·Fan Out**을 '색 미정'으로 둘지, Q2 후보에서 뺄지.
4. **기본 색 조합**의 흰색을 Warm White와 Cool White 중 어느 쪽으로 할지.

## 문구를 바꿀 때의 영향 (아직 재지 않음)

- `color_tendency`는 Q2 밖에서도 읽힌다. `interview.py`에서 15곳, `web/session.py` 8곳, `section_palette.py` 2곳, `orchestrator/tools.py` 2곳이다(`grep -rn color_tendency server`, 시험 제외).
  예를 들어 무드 문구를 바꾸면 구간 무드 해석과 린트가 같이 바뀔 수 있다. 문구를 고치는 카드에서 8곡 게이트와 함께 다시 재야 한다.
- t483 이후에는 문구 앞머리에 표준 어휘가 오고 뒤에 색 이름이 와도 색 이름이 주색이 된다(`쿨 볼드 블루` → `블루`).
  색 이름을 넣는 위치는 제약되지 않는다.
