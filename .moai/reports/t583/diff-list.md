## 안 잰 것

- 실기 콘솔·실기 곡 데이터 0회 — 화면 값의 「미정」·빈 칸 상당수는 제품 기본 격자 데이터 탓(⚪ 표시)이다. 프리셋이 채워진 곡으로는 찍지 않았다.
- 세로 1000px 한 가지 높이만 쟀다. 더 큰 창(1200·1440)에서 타임라인 높이가 얼마가 되는지는 재지 않았다.
- ✎ 편집 입력, 이음매 ◆ 클릭, 곡 전체 확대, 2D 무대 장비 클릭, 프리셋 서랍은 누르지 않았다.
- 시안은 문서 안에 고정 높이 틀로 들어 있고 앱은 창 높이에 맞춘다 — 높이 비교는 「같은 1000px 창에서 보이는 양」 기준이다.
- 원인(어느 CSS 규칙이 171px 를 만드는지)은 조사하지 않았다 — 카드 범위 밖(목록만).
