## 2. 증거 — 쪼개면 무엇이 깨지나

카드가 「먼저 재라」고 지목한 미측정 항목(절 번호를 인용하는 문서 수)을 쟀다.

```
$ git grep -h -o (규약 §[0-9.]*) origin/main | sort | uniq -c | sort -rn
  19 규약 §3
   3 규약 §5
   2 규약 §6
   1 규약 §7 · 1 규약 §5. · 1 규약 §4.1 · 1 규약 §4.0 · 1 규약 §1
```

총 29건. 그중 **§3 이 19건**이고, 결정적으로:

```
$ git grep -n (규약 §) origin/main -- server/tests
test_groupgen_write.py:163 · test_lxseq_group_section_request.py:283
test_lxseq_tool.py:1003 · test_section_refusal_reason_survives.py:49,210,244,257,374
```

**8건이 살아 있는 검사 코드 안**에 있다. 보고서가 아니라 `server/tests/` 다.

쪼개서 뒤 절을 밀면 §4.0·§4.1·§5·§6·§7 인용 8건까지 함께 어긋나 **29건 중 27건**이
흔들린다. 그리고 낡은 `§N` 을 잡아 주는 기계가 **없다** — 주석과 산문이라 조용히 썩는다.
절 번호는 산문이 아니라 **주소**다.

### 회차 중에 붙은 후보 둘 (같은 세션에서 실측)

- **(g) 「근거가 실행인가 추론인가」로는 부족하다 → 「그 실행의 명령줄은 무엇인가」.**
  이 세션에서 난 사고다. 레인이 저장된 덤프가 잘렸다며 바이트 수와 md5 를 들고 왔고,
  근거는 분명히 **실행**이라 기존 술어를 통과했다. 실제로 자른 것은 레인 자신의
  `| head -80` 이었다. 리드(나)가 그것을 「독립 확인」으로 적어 승격시켰고 거짓 결론이
  배차 요청·리드 승인·새 카드(t192)까지 갔다. 내가 잰 것은 내 파일 크기뿐이었고
  그 값은 **두 가설 모두와 양립**했다 — 대조군이 아니었다. → 3.6
- **(h) §9 의 `session_id` 불일치 처방 강화.** t185 실측이 근거다 — 공유 트리에서
  남의 값이 찍히면 **`raw_pct` 를 버리고 카드 수 축으로 간다**를 명시했다.
  같이 넣은 것: 자기보고 오차가 **단조 증가**한다는 기전(마지막 실측에 느낌을 누적하므로).
  카드가 「카드 수 축을 약화시키지 마라」고 적었고, 그 반대로 **대체 경로**임을 명시했다. → §9
