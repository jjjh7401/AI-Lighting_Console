## 2. 기전 — editable .pth 실물

각 트리의 venv 에 `_editable_impl_ma3_copilot_server.pth` 가 있고, 내용은 **그 트리의 루트 한 줄**이다.

    t80 venv 의 .pth  ->  /.../.claude/worktrees/t80
    t86 venv 의 .pth  ->  /.../.claude/worktrees/t86

server 임포트가 sys.path 를 훑을 때 앞쪽에 자기 트리가 없으면 이 .pth 가 해소한다.
즉 **인터프리터가 트리를 데려온다.**

## 3. 위험 재현 — 6팔 실측

cwd 는 전부 t80 루트. 스크립트는 전부 t80 의 파일. 인터프리터만 바꾼다.

| 팔 | 형태 | sys.path[0] | 임포트된 server | 경고 |
|---|---|---|---|---|
| A | 내 인터프리터 + 스크립트 경로 | t80/server/tools | **t80** OK | — |
| B | **빌린 인터프리터(t86) + 스크립트 경로** | t80/server/tools | **t86** 위험 | **0줄** |
| C | 빌린 인터프리터 + -m | t80 | t80 OK | — |
| D1 | 빌린 인터프리터 + -c | (cwd) | t80 OK | — |
| D2 | 빌린 인터프리터 + **-P** -c | (cwd 제거됨) | **t86** 위험 | **0줄** |
| E | uv run + 어긋난 VIRTUAL_ENV | t80/server/tools | t80 OK | uv 가 경고 후 무시 |
| F | 빌린 인터프리터 + -m pytest | — | t80 OK (4 passed) | — |

**B 가 이 카드의 본체다.** 스크립트 경로 실행은 sys.path[0] 이 server/tools/ 라
자기 트리 루트를 담지 않는다. 가릴 것이 없으니 .pth 가 이기고, 남의 트리 코드가
**아무 신호 없이** 돈다.

**D2 는 「가려진 것은 운이다」의 증거다.** 지금 안전한 -c / -m 형태도 -P 플래그
하나면 그대로 뒤집힌다. C·D1 의 안전은 구조가 아니라 기본값에 기대고 있다.

재현에 쓴 프로브는 측정 후 삭제했다. 내용은 cwd / sys.executable / sys.path[0] 을
찍고 server 를 임포트해 server 의 파일 경로를 찍는 6줄짜리다.
