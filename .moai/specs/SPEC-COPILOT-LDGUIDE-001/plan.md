## §A. 접근 요약

### §A.1 이 SPEC의 한 줄

**앱보다 뒤처진 사용 가이드를, 감독의 시간축 9단계로 다시 세우고, 모든 능력 주장을
실측 원장에 귀속시킨다. 그 과정에서 비는 칸이 곧 다음 SPEC의 입력이다.**

### §A.2 되돌리기 어려운 결정 우선순위 (리뷰 순서 — 빌드 순서 아님)

리뷰는 바뀔 가능성이 큰 것부터 본다. 아래 1~3이 뒤집히면 본문 전체를 다시 쓴다.

1. **9단계 축 확정** — 사용자 확인 완료(2026-08-17). 뒤집히면 전면 재구성.
2. **3부 구조(감독이 하는 일 / 앱이 대신함 / 한계)** — 이 SPEC의 핵심 발명. ③이 백로그
   도출의 유일한 공급원이므로, ③을 뺀 구조는 목표 (2)를 달성하지 못한다.
3. **증거 원장 분리** — 근거를 본문 밖에 두는 결정(REQ-LDG-004/007 동시 충족 수단).
   합치면 감독 언어가 깨지고, 없애면 주장이 근거를 잃는다.
4. **참조 부록 존치**(Q4) — 국소 결정. 뒤집혀도 부록 절만 삭제.
5. 문체·표 서식 — 기계적. 마지막.

### §A.3 빌드 순서가 다른 이유

리뷰는 3부 구조부터 보지만, 빌드는 **증거부터** 한다. 근거 없이 본문을 쓰면 §A.1의
결함(주장이 실제와 어긋남)을 그대로 재생산한다. M0가 끝나기 전에는 본문 한 줄도 쓰지 않는다.

### §A.4 M0 게이트 — 축별 분기 (모두 유효한 출력)

| 게이트 | GO 분기 | NEGATIVE 분기 |
|---|---|---|
| **A. 단계 3(포커싱) 도구 존재** | 조준 도구가 노출됨 → 단계 3 ②에 기재 | 노출 안 됨 → 단계 3 ③(한계) + 백로그 항목 1건. **둘 다 유효** — 없다는 것도 결과다 |
| **B. 단계 7(리허설·수정) 지원** | 전용 기능 존재 → 단계 7 ②에 기재 | 저수준 명령뿐 → 단계 7 ③ + 백로그 항목 |
| **C. 식별자 부재 16건 판정** | 산문으로 덮임 → 용어만 정비 | 실제 누락 → 단계별 ②에 신규 서술 |
| **D. 안전 경고 4건 근거 재확인** | 원문 확인됨 → 경고 배치 | 확인 실패 → 그 경고는 **싣지 않는다**(REQ-LDG-008) |

**`ok:true`는 증거로 쓰지 않는다.** 도구 설명문에 적힌 능력 주장도 증거가 아니다 —
설명문은 LLM에게 주는 지시문이지 동작 증명이 아니다. 코드 경로 확인 또는 테스트가 근거다.

   주장 전부(REQ-LDG-009). 1회차 감사는 이들의 존재만 확인하고 진위는 재지 않았다.
2-b. **역방향 전수 대조**(§A.4 확장): 가이드에 등장하는 모든 스네이크케이스 토큰을 뽑아

2-c. **보존 판정 모집단 고정**: 개정 전 `<h3>` **25개** 각각에 `keep` / `merge` / `drop`

5. **게이트 D** — 안전 경고 4건의 근거를 원문에서 재확인.

### §C.2 기존 파일의 성질 (회귀 금지 대상 — 실측)

**측정 시각 2026-08-17, HEAD `fe7ba80` 기준. 아래 명령은 전부 실행 검증됐다** —
1회차 감사 D1이 지적한 `\|`(문자 그대로의 파이프) 파손을 `|`(선택)로 교정한 뒤 재측정했다.
교정 전 값도 우연히 같았으나, 그 값은 "명령이 아무것도 묻지 않아 나온 0"이므로 귀속 불가였다.

| 성질 | 측정값 | 비고 |
|---|---|---|
| 외부 URL | 0 | 자체완결 |
| `<script>` / `<link>` | 0 | 인라인 `<style>` 1개만 존재 |
| `<h2>` | 13 | |
| `<h3>` | **25** | AC-011 보존 판정의 모집단 |
| 목차 앵커 | 12 | |
| 크기 | 55,212 B | |

측정 명령 (표 밖 코드블록 — 마크다운 이스케이프가 개입하지 않는다):

```bash
G=docs/user-guide.html
grep -coE 'https?://[^"'"'"' ]+' "$G"          # 0
grep -cE '<script|<link' "$G"                  # 0
grep -oE '<(script|link|style)[^>]*>' "$G"     # <style> 1건
grep -c '<h2' "$G"                             # 13
grep -c '<h3' "$G"                             # 25
grep -oE 'href="#[^"]+"' "$G" | wc -l          # 12
wc -c "$G"                                     # 55212
```

> **D1 재발 방지 규약 [HARD]**: grep 명령은 **반드시 코드블록에** 둔다. 마크다운 표
> 셀에 넣으면 파이프를 `\|`로 이스케이프하게 되고, `grep -E`는 `\|`를 선택이 아니라
> **문자 그대로의 파이프**로 읽어 어떤 입력에도 0을 반환한다 — 상시 통과하는 가짜 검사가
> 된다. 1회차 감사 D1이 정확히 이 경로로 발생했다.

### §C.3 증거 규율의 적용점

이 SPEC의 산출물은 코드가 아니라 **주장의 집합**이다. 따라서 통상의 테스트 대신
**증거 원장 대조**가 품질 게이트다. 원장에 행이 없는 주장은 본문에 실을 수 없다.
