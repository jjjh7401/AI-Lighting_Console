# SPEC-COPILOT-SONGSTD-001 — 수용 기준

## M1 (엔진 코어)

- [ ] 통합 무드 사전: 항목마다 (D, 색 성향, 포지션 후보) 3튜플, 키워드
  전체 무겹침 테스트 고정, 우선순위(구간>컨셉>장르>기본) 충돌 케이스 통과.
- [ ] 예산 함수: BPM 60 vs 180에서 같은 D의 페이드 초가 3배 비율,
  D 상승열의 디머 단조성, 장르 오버레이 반영 — 유닛 green.
- [ ] 린트 L1~L14: 규칙별 위반/통과 쌍, Seq 114 실측 결함이 L2로 검출.
- [ ] ruff clean, 기존 스위트 무파손.

## M2 (표준 포지션+디머 시트)

- [ ] 같은 12구간·같은 무드 입력에서 구간별 디머·페이드가 D레벨에 따라
  달라진 시트 생성 (전 큐 100% 금지 — L2 통과).
- [ ] 세션 어휘에 BPM·장르 파싱, 린트 보고 병기, 카드 관례 유지.
- [ ] 라이브: 새 시퀀스 3D 밝기 합이 D2<D3<D4<D5 계단, D2 페이드 프레임
  수 > D5 페이드 프레임 수 (BPM 환산 검증).

## M3 (컬러 통합)

- [ ] 팔레트 3~5색 강제(C1), 프런트/키층 중립 규칙(C3), 컨셉 시드→카드.
- [ ] 번들이 프리셋 리콜+컬러(+페이저)를 한 프로그래머 상태로 저장,
  `/Merge` 부재를 테스트로 고정.
- [ ] 라이브: 페이저 큐 프레임 diff ≠ 0, 프레임 색 히스토그램이 팔레트
  내 색만 표시.

## M4 (오디오 파이프라인)

- [ ] 합성 정답 트랙 회귀: BPM 오차 ≤3%, 경계 ±1s, 구간 D 등급 일치.
- [ ] 업로드→DSP→카드→시트 흐름에서 LLM이 BPM/박자를 결정하는 경로 부재
  (구조 테스트).
- [ ] 서버 기동·기존 테스트가 librosa 미로드 상태로 통과 (지연 import).
- [ ] 라이브: 실제 곡 1개 업로드 → 확인 카드 → 시트 저장 → 콘솔 재생.

## 공통

- [ ] 새 함정 스킬 기록, 각 M 커밋·푸시, 검증은 운영자 플로우(Go 횟수)로.
