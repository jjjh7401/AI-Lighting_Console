# 8곡 연출 판독 결과와 수정 범위 제안

- 작성: 2026-10-01, 팩토리 리드
- 근거: `.moai/reports/t499/verdict.md`(8곡 오프라인 판독, 콘솔 접촉 0) · `.moai/reports/t498/verdict.md`(Rain 실기, 감독 0점)
- 상태: 수정 범위 **감독 확정 전**

## 1. 결론

8곡 모두 Rain과 같은 모양이다. 원인은 곡이 아니라 **콘솔 명령을 만드는 함수 한 곳**(`server/design/song_cue_render.py` `reviewed_song_commands`)이다. 설계 층은 곡마다 색 조합 2~4종, 포지션 6~8종, 효과 요청 6~36건을 만든다. 송신 층에 오면 이것이 다음으로 접힌다.

| 항목 | 설계 층 | 송신 층 (8곡) |
|---|---|---|
| 곡 전체 색 | 색 이름 3~4종 | **1색**(7곡, RGB 5·20·100) · DinoDino 2색(우연) |
| 큐 간 색 변화 | 보조색 3~11회 | **0회**(7곡) |
| 기구 선택 | 매핑 카드에서 층별 역할 승인 | **86대 한 묶음** |
| 서로 다른 값을 받는 그룹(8개 중) | — | **최대 2개**(BACK·BLIND) |
| 효과 | 요청 6~36건, 페이저 제안 104큐 | **0줄** |
| 포지션 | 6~8종 | 6~8종(살아남음, 다만 86대 전체에 같은 프리셋) |

Rain은 가짜 콘솔 송신과 실기 송신이 W 채널 줄을 빼고 순서까지 같다(잰 값). 나머지 7곡은 가짜 콘솔만 쟀다.

## 4. 바뀐 검증 기준 (이 SPEC의 완료 조건)

1. **오프라인 연출 판독(8곡 전부)** — 송신 기준
   - 곡 전체 색 2~3색, 큐 간 색 변화 1회 이상
   - 구간 큐마다 서로 다른 값을 받는 층 3개 이상
   - 효과를 요청한 곡은 송신 효과 줄 1줄 이상
   - §6 밝기 대역 위반 0
   - 블라인더·스트로브가 액센트 큐 밖에서 켜지는 것 0
2. **실기 감독 판정** — 판독을 통과한 곡만 콘솔에 올린다. 곡 점수 3점 이상이 통과
3. **기계 동작** — t498에서 확인한 A1~A7·C 항목(회귀 확인용)

## 5. 안 잰 것

- 나머지 7곡의 실기 송신(가짜 콘솔만)
- 효과 허용이 0인 원인(리그 능력 판독 추정)
- 인터뷰 답을 곡마다 바꾸면 설계 층이 달라지는지(이번엔 8곡 같은 답)
- 무대에서 보이는 결과(판독은 명령 수준)
