# M7 디자인 제약 — 해서는 안 되는 것

Claude Design 산출물을 받아 구현으로 옮기기 전에 이 목록으로 먼저 걸러낸다.
목록에 걸리는 산출물은 폐기하고 재작업을 요청한다(H3 — 1:1 재현, 임의
디자인 변경 금지).

## 기술 스택

- React + 순수 CSS(`ui/src/styles.css` 한 파일) 외 어떤 프레임워크·
  컴포넌트 라이브러리도 추가하지 않는다 — Tailwind 금지, shadcn/ui 금지,
  MUI/Chakra/Ant 등 금지. `ui/package.json`의 실측 의존성이 `react` +
  `react-dom` 정확히 둘뿐이다(2026-09-22).
- CSS-in-JS, CSS Modules, styled-components 도입 금지 — 기존 관행(단일
  전역 CSS 파일 + BEM류 클래스명)을 따른다.

## 정보 구조

- 새 화면, 새 라우트, 새 내비게이션 메뉴 금지.
- 기존 5블록(오늘의 곡·큐 순서 → 타임라인 → CUE SHEET → PLAN CUE 카드 →
  상태줄)의 순서·존재를 바꾸지 않는다.
- 전면 재설계(레이아웃 그리드 자체를 새로 짜는 것) 금지 — 국소적 추가만.

## 테마·비주얼

- 라이트 테마 제안 금지. 다크 테마 유지가 전제다.
- `--live-amber`(`#ffb02e`)는 "실행 중인 풀 타일"에만 쓰는 예약 토큰이다
  — 다른 용도(예: 경고 배지)에 재사용 금지.
- 색만으로 상태(통과/경고/실패, 근거 등급, Track 예외 여부)를 구분하는
  디자인 금지 — 항상 아이콘·모양·텍스트를 함께 쓴다.

## 카피·언어

- 비유 표현 금지 — "따뜻한 조명", "부드러운 전환" 같은 표현 대신 실제
  값(색 이름 + HEX, 밝기 %, 그룹 이름, 초 단위 시간)을 쓴다.
- 영어 용어를 주 라벨로 쓰지 않는다 — 한글이 주, 영어는 보조로 작게
  병기만.
- 컨셉 패널의 인과 불릿은 워크시트 `concept` 필드 원문이다 — 디자인
  과정에서 문장을 요약·재작성·윤문하지 않는다(REQ-032).

## 범위 밖 기능 — 이런 컨트롤을 그리지 않는다

`spec.md` §4 비목표에서 가져온 목록. 이 기능들을 위한 버튼·토글·패널을
Claude Design이 그려 오면 전부 폐기 대상이다.

- **객석광** 그룹 — 현재 리그 18그룹에 없다.
- **Gobo·Prism** 속성 — 스키마에 노출되지 않는다.
- **LED·영상 연동**.
- **방송 특화 기능** — Camera Base 독립 플레이백, Intended Shot, Take
  Variant, 카메라 컷 번호↔큐 번호 매핑(목표 무대는 콘서트, 방송 아님).
- **grandMA2 / ETC Eos / MagicQ / Avolites 등 MA3 외 콘솔 전환 UI** — 이
  앱은 grandMA3 전용이다.
- **콘솔 명령 실제 방출 관련 UI**(Block/Track/Cue Only/Release의 실제
  MA3 명령, 축별 딜레이 문법, Mark 큐 문법) — M8 콘솔 프로브 이후 별도
  SPEC 대상, M7은 이 값을 화면에 "표시"만 하지 실제 방출 컨트롤을 두지
  않는다.
- **원샷 어휘 중 자동 생성 안 되는 3종**(Kick·Snare·Cymbal accent, Color
  bump, Position snap)을 위한 "자동 생성" 버튼 — 어휘 목록에는 있으나
  기본값이 없고 워크시트 입력 전용이다. UI에 자동화 컨트롤을 넣지 않는다.
- **리허설 피드백 학습 루프** UI — 프리셋·타이밍·색 자동 보정 화면 없음.

## 데이터

- 목업 텍스트("Lorem ipsum", "샘플 곡 1")를 쓰지 않는다 — `handoff-
  brief.md` §5의 Rain 실데이터를 그대로 쓴다.
- 존재하지 않는 근거 등급, 트래킹 모드, 원샷 종류를 새로 지어내지 않는다
  — 각각 정확히 4종·4종·7종으로 닫혀 있다(REQ-022, REQ-053, REQ-007).
