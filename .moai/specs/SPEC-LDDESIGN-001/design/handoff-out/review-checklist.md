# M7 디자인 수령 검토 체크리스트

Claude Design 산출물이 돌아왔을 때 확인하는 표. AC-LDDESIGN-018~020과
REQ-LDDESIGN-078~085에 1:1로 묶는다. 한 줄에 하나씩 확인 가능한 형태로
적는다 — 표시가 안 되면 그 줄은 FAIL이고 캔버스 수정 요청 대상이다(H3).

## REQ 단위 체크

| REQ | 확인 문장 | 통과 조건 |
|---|---|---|
| REQ-078 | 기존 5블록 순서가 그대로 보이는가 | 오늘의 곡·큐 순서 → 타임라인 → CUE SHEET → PLAN CUE 카드 → 상태줄, 5개 전부·이 순서대로 |
| REQ-079 | 컨셉 패널이 기본 접힘이고 한글 라벨 3개가 정확한가 | "이 곡의 연출" / "이 곡의 재료" / "지키는 것·하지 않는 것·아껴 두는 것" — 문구가 이와 다르면 FAIL. 항목 클릭 시 4칸(무슨 뜻/무대에서/왜/바꾸려면) 펼침 동작이 그려져 있는가 |
| REQ-080 | 연출 설명이 인과 불릿 + 6칸 문법표인가 | 6칸 헤더가 정확히 "구간 / 색 / 기구·밝기 / 움직임 / 효과 / 그래서 보이는 것"인가. 모든 셀이 실제 값(색 이름+HEX, 밝기 %, 그룹 이름)이고 비유 표현이 하나도 없는가 |
| REQ-081 | 타임라인 블록 색 = Color Strip, 원샷·Mark가 점 줄로 겹쳐 있는가 | 타임라인 색이 §tokens.md 팔레트(노랑/파랑/흰색/주황)와 일치, 점 줄이 타임라인과 별도 행으로 겹쳐 그려져 있는가 |
| REQ-082 | CUE SHEET가 정확히 14열인가 | 기존 12열 + `Trigger` + `Track 예외` = 14. 그 이상·이하면 FAIL. `Track 예외` 열이 기본값(`Track`)일 때 빈 칸으로 그려져 있는가 |
| REQ-083 | PLAN CUE 카드 하단 3줄 + Q### 배지 | `Fade/Track` · `MIB/남김` · 헤드룸 요약 3줄이 카드 하단에 있는가. `Q###` 배지가 카드에 보이는가 |
| REQ-084 | 상태줄에 GATE 표시가 있는가 | PASS/WARN/FAIL/N/A 4상태가 색만이 아니라 아이콘·텍스트로도 구분되는가 |
| REQ-085 | 스크롤 연동 + 영어 보조 표기 | 타임라인↔CUE SHEET 스크롤 연동이 동작(또는 그 동작을 설명하는 인터랙션 노트)으로 명시돼 있는가. 영어 용어가 작은 보조 표기로만 쓰였는가(주 라벨이 한글인가) |

## AC 단위 체크

| AC | 확인 | 통과 조건 |
|---|---|---|
| AC-018 | 첫 화면 상태 | 5블록 유지 + 컨셉 패널 접힘 + 클릭 시 4칸 펼침 + 인과 불릿 원문 + 6칸 표(실제 값) |
| AC-019 | Q### 3곳 동일 + CUE SHEET 2열 추가 | 타임라인 Q줄·CUE SHEET·PLAN CUE 카드에서 같은 큐의 `Q###`가 시각적으로 같은 값·같은 스타일로 확인되는가. CUE SHEET 12→14열(정확히 2열 추가)인가 |
| AC-020 | 스크롤 연동 + 색 일치 + GATE | 긴 곡(35+ 큐, 예: Too Cool) 시나리오를 고려한 스크롤 상태가 디자인에 있는가. 타임라인 색과 Color Strip 값 일치. 상태줄 GATE 표시 존재 |
