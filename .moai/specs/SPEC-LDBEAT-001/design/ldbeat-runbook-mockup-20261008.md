## 화면
- 런북 모드에 새 블록 「박자 배치 — 역할 × 마디」. 기존 블록은 그대로.
- 격자: 열 = 마디(0~25, 음악 시각), 행 = 역할 6(SCENE·BACK PULSE·SIDE CHASE·MOVER-U·MOVER-D·ACCENT). 칸 색 = 그 역할 색, 막대 = 밝기, 글자 = 효과, 주황 세로줄 = 그 마디에서 바뀜.
- 마디를 누르면: 무대 개념도(색·밝기·빔 움직임 애니메이션) + 역할별 표.

## 마디마다 역할별로 보이는 것 (8)
장비(그룹·번호·대수·기종) · 밝기(숫자, 펄스면 낮은↔높은) · 위치 프리셋(번호·이름) · 색 프리셋(번호·이름·견본) · 효과 프리셋(번호·이름 — 종류·한 바퀴 박 수) · 이 마디에서 바뀐 것 · 콘솔 위치(Seq·Cue·큐 이름·TC 트랙·이벤트 시각) · 실기 확인 상태. 펼치면 그 큐의 실제 명령 줄.

## 프리셋 방식 (감독 2026-10-08: 「위치·색·효과는 프리셋을 잡아 저장하고 프리셋 번호를 보여줘」)
- 색(풀 4)·위치(풀 2)·효과(종류별 풀 — 아래 「효과 프리셋 풀」)는 프리셋으로 저장, 큐는 `At Preset p.n` 참조. 밝기는 값 / 디머 프리셋 / 디머 효과 중 하나(한 큐에 하나만).
- 0~25마디 프리셋 25개(예시 번호): 색 4.21~4.25 · 위치 2.41~2.46 · 효과 1.21~1.26(디머 풀), 2.61~2.68(위치 풀 — 움직임은 상대값), 밝기 1.31~1.33. 콘솔 이름 「LA …」.
- 화면: 칸에 효과·색 프리셋 번호, 표에 프리셋 칩. 칩을 누르면 쓰는 큐·칸 수를 보여 주고 격자에 표시 — 고치면 그 큐가 한꺼번에 바뀜.
- 고치기 두 길: 프리셋 자체(쓰는 곳 전부) / 이 칸만 다른 프리셋으로.
- 근거: [잰 것] 프리셋 참조 큐 저장(CUETIME Seq 101 Cue 1 → Preset 2.28, 시트에 「2.28 Cro…」) · 효과 프리셋 저장(FXLIB `Store Preset p.n 'name' /Universal`, t513 4.10·21.7) · 빈 번호 검사(phaser_pregen PRESET_OCCUPIED).
- [미확인] 프리셋을 고치면 참조 큐가 따라 바뀌는지 · 한 큐에 프리셋 셋 참조 · 효과 프리셋이 스피드 마스터 15·Measure 를 지니는지(지금까지 고정 속도 At Speed 30 만) · 움직임 효과를 위치 프리셋 위 상대값으로.
- 결정: 새 프리셋 세트 vs 쇼 기존 프리셋(권고: 섞어서) · 밝기는 값·디머 프리셋 둘 다 허용(감독 2026-10-08) · 앱이 만든 이 곡 프리셋 덮어쓰기 허용(덮어쓰기 금지 규칙 예외).

## 이름 규칙 (감독 2026-10-08)
- 콘솔에 들어가는 이름(프리셋·큐·시퀀스·타임코드)은 영문·숫자만 — 콘솔은 한글 이름을 못 씀. 앱 `_ascii_label`(songcue.py:683)은 한글을 지움(t513). 화면에는 콘솔 이름(예: `4.24 LA Pink`)을 먼저, 한글은 설명으로만.

## 효과 프리셋 풀 (감독 2026-10-08 논의, 리드 권고)
- 종류별 풀: 위치 효과 → 위치 풀 2(상대값, 2.61~) · 색 효과 → 색 풀 4(4.41~) · 밝기 효과·고정 밝기 → 디머 풀 1 · 섞인 효과만 이 곡용 All 풀 22.
- 이유: 종류별 풀의 기본 입력 필터가 콘솔에서 사람이 직접 고칠 때 다른 값 섞임을 막음(공식 문서). 앱 phaser_pregen 도 같은 방식(Color/Dimmer/All 1).
- 장치: 허용 속성 목록(위치=Pan·Tilt, 색=ColorRGB, 밝기=Dimmer/Dimmer2) 밖이면 저장 거절 · 저장 직전 ClearAll · 승인=송신 대조 · 번호 대역+「LA …」 이름, 앱이 만든 것만 수정.

## 칸마다 고치는 세 방법 (감독 2026-10-08: 「프리셋만 있으면 안 됨 — 자연어, 직접 선택, AI로 프리셋 만들기」)
| 방법 | 동작 | 현재 앱 |
|---|---|---|
| ① 직접 고르기 | 칸 ✎ → 밝기(값/디머 프리셋/디머 효과)·위치·색·효과 목록 선택(이 곡 + 쇼 기존 + 새 프리셋) → 즉시 초안 반영 | 새로(프리셋 이름 읽기는 있음) |
| ② 문장으로 | 정해진 꼴 「(마디) (역할) (항목)을 (값)으로」 → 규칙 파서, 즉시·결정적 | 큐 단위 파서만 있음(`cue_sheet_edit.py`) — 마디·역할 문장은 새로 |
| ③ AI에게 | 느낌·새 프리셋 요청 → AI 제안 카드(바꿀 칸 + 새 프리셋) → 감독 「적용」 | 효과 프리셋 도구 있음(`find_fx`·`instantiate_fx`·`compose_fx`), 위치는 조준 도구(`pointing.py`) — 색 프리셋 생성·격자 제안은 새로 |
- 모든 길은 같은 서버 검사를 거쳐 초안만 바꿈. 콘솔은 「고친 것 콘솔에 반영」 승인 1회(새 프리셋 N개 + 다시 저장할 큐 M개 표시)에서만. AI 는 제안만.

## 「이 마디 콘솔에서 보기」
1. 곡 한 번 쓰기 — 역할 시퀀스 6 + TC 1, 승인 1회 [잰 것: t520 같은 꼴 587줄]
2. ▶ 보기 — `Goto Cue k Sequence S` × 6(쓰기 없음) [잰 것: `Goto Cue 1 Sequence N` 한 줄, t520 §16-2 · 미확인: 2번 이후 큐, 6줄 동시]
3. 켜진 채 대기, 효과는 스피드 마스터에 맞춰 계속 [잰 것]
4. 다음 마디 = 바뀐 역할만 Goto · 끄기 = `Off Sequence` × 6 [잰 것]
- 이 마디부터 음악과 재생: 미확인(TC 중간 재생 명령 안 잼, 확인된 건 `Top Timecode`뿐)
- 미리보기는 마디 첫 박 상태. 마디 중간 변화(17마디 3박)는 칸을 나눔.

## 고치기
범위·역할·항목(밝기/색/위치/효과)을 정해진 목록에서 선택 → 앱이 문장 생성 → 서버 판정(적용/거절 이유 하나) → 무대 그림 또는 ▶ 보기 → 「바뀐 마디 콘솔에 다시 쓰기」(승인 1회, 제안).
