1. 런북 모드 화면 — 직접 눌러 보세요

마디 번호(또는 칸)를 누르면 그 마디의 무대 그림과 역할별 프리셋이 나와요. 프리셋 칩을 누르면 쓰는 곳이 격자에 노란 테두리로 표시돼요. 역할 줄의 ✎ 고치기를 누르면 아래에 고치기 창이 열려요 — 「직접 고르기」에서 바꾸면 격자가 바로 바뀌어요(시안 안에서만).

2. 칸마다 고치는 세 가지 방법

어느 방법으로 고치든 마지막에 고치는 곳은 서버 한 군데예요. 서버가 값이 맞는지 검사한 뒤 초안(격자)을 바꾸고, 콘솔에는 「⇪ 고친 것 콘솔에 반영」을 눌러 승인할 때만 가요. AI도 직접 콘솔에 쓰지 못하고 제안만 만들어요.

방법이럴 때어떻게바로 바뀌나지금 앱에 있나
① 직접 고르기바꿀 프리셋을 알 때칸 → ✎ → 밝기(값 또는 디머 프리셋) · 위치 · 색 · 효과를 목록에서 선택. 목록에는 이 곡 프리셋 + 쇼에 이미 있는 프리셋 + 「＋ 새 프리셋」예 — 고르는 즉시 격자·무대 그림이 바뀜새로 만듦 제안 (프리셋 이름 읽기는 있음)
② 문장으로짧게 정확히 말할 때「22~25마디 아래 무빙 효과를 틸트 웨이브 1박으로」처럼 정해진 꼴로 입력 → 앱이 알아들은 내용을 보여 주고 적용예 — 규칙으로 알아들어서 즉시, 결과가 늘 같음큐 단위 문장은 있음(큐시트 편집) · 마디·역할 단위 문장은 새로
③ AI에게원하는 느낌만 있을 때, 새 프리셋이 필요할 때「코러스 1 아래 무빙 더 화려하게」 「핑크보다 진한 마젠타 만들어」 → AI가 바꿀 칸 목록 + 필요한 새 프리셋을 제안 카드로 보여 줌 → 「적용」을 눌러야 바뀜제안을 확인하고 「적용」을 누르면효과 프리셋 만들기 도구는 있음(find_fx·instantiate_fx·compose_fx) · 위치 프리셋은 무대 지점 조준 도구 있음 · 색 프리셋 만들기·격자 제안은 새로

AI 제안도 ①·②와 똑같은 서버 검사를 거쳐요. 없는 프리셋·실기 미확인 효과·허용 밖 속성은 이유와 함께 거절돼요. 새 프리셋은 콘솔에 반영할 때 승인 카드에 「새로 만드는 프리셋 N개」로 함께 나와요.

4. 효과 프리셋은 종류별 풀에 — 실수를 막는 장치

효과풀이 시안 번호(예시)
팬·틸트 움직임위치 풀 2(기본 위치 2.41~ 와 대역 분리)2.61~2.68
밝기 펄스·체이스 / 고정 밝기디머 풀 11.21~1.26 / 1.31~1.33
색 효과색 풀 4(색 4.21~ 와 대역 분리)4.41~ (이 범위엔 없음)
섞인 효과(밝기+색 등)이 곡용 All 풀 2222.x (이 범위엔 없음)
  • 허용 속성 목록: 위치 효과는 Pan·Tilt만, 색 효과는 ColorRGB만, 밝기는 Dimmer(Spiider 는 Dimmer2)만 — 목록 밖 줄이 있으면 저장 거절
  • 저장 직전 비우기: ClearAll → 그 프리셋의 선택·속성 줄만 → 저장(t520 꼴)
  • 승인한 그대로 보냈는지 대조(t512 비교기) — 콘솔은 프리셋 내용을 읽어 주지 않아서(t516) 보낸 줄로 증명
  • 번호 대역·이름 「LA …」 — 앱은 자기가 만든 프리셋만 고치고, 쇼에 원래 있던 프리셋은 건드리지 않음
  • 콘솔에 들어가는 이름은 영문·숫자만(프리셋·큐·시퀀스·타임코드) — 콘솔은 한글 이름을 못 씀. 앱의 이름 정리(_ascii_label)가 한글을 지워 버리므로(t513 확인) 만들 때부터 영문 이름을 정하고, 한글은 앱 화면의 설명으로만 보여 줌
  • 종류별 풀의 기본 입력 필터가 감독님이 콘솔에서 직접 고칠 때도 다른 값이 섞이는 걸 막아 줌(공식 문서)
