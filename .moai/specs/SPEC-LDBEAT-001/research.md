# SPEC-LDBEAT-001 — 현재 구현 대조 (research.md, Tier L 신설 — 카드 t554)

이 문서는 design.md가 매핑한 시안 23개 항목(§3 표)을 현재 구현(`ui/src/App.tsx`·`ui/src/components/BeatGrid.tsx`·`ui/src/components/RunbookMode.tsx`)과 항목별로 대조한다. 분류는 네 값 중 하나다 — **구현**(시안대로 동작), **부분**(일부만 일치 또는 데이터가 있을 때만 동작), **미구현**(코드에 없음, grep 0건), **상충**(시안과 다른 동작). 전부 이 plan-phase가 직접 읽거나 그렙한 결과이며, 추측으로 분류한 항목은 0건이다 — 명령/출력은 각 행에 인용했다.
